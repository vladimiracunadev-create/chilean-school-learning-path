# Checklist

- [ ] LICENSE = MIT puro.
- [ ] LICENSE-CONTENT.md existe.
- [ ] LICENSING.md clasifica el alcance.
- [ ] DATA-LICENSE.md existe si hay datos.
- [ ] Cada dataset tiene procedencia/licencia.
- [ ] THIRD_PARTY_NOTICES.md actualizado.
- [ ] No se relicenciaron terceros.
- [ ] No hay textos escolares completos sin derechos explícitos.
- [ ] No hay imágenes externas sin licencia.
- [ ] No hay `UNKNOWN` redistribuidos.
- [ ] No hay datos personales/secretos indebidos.
- [ ] README explica las licencias.
- [ ] Validador y tests pasan.
- [ ] Dependencias conservan avisos.
- [ ] Marca/logos tienen política separada.

## Antes de vender
- [ ] Revisar compatibilidad comercial de terceros.
- [ ] Revisar datasets/modelos.
- [ ] Revisar imágenes/medios.
- [ ] Definir contrato/licencia comercial.
- [ ] Revisar marca, privacidad y datos personales.
- [ ] Solicitar revisión jurídica si el riesgo económico lo amerita.
