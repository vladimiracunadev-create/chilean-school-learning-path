📊 Rúbrica de evaluación

Rúbrica transversal para 1° básico

⬅️ Centro de documentación · 📘 Syllabus · 🧑‍🏫 Guía docente · ✅ Protocolo de revisión

La rúbrica ayuda a interpretar evidencia y decidir qué hacer después. No reemplaza instrumentos disciplinares, políticas del establecimiento ni juicio profesional.

Principios

  1. Se evalúa el OA, no rasgos personales.
  2. La evidencia debe ser observable y atribuible al estudiante.
  3. Una barrera de acceso no se interpreta automáticamente como falta de aprendizaje.
  4. La categoría orienta una intervención y exige volver a comprobar.
  5. El ticket de salida no se convierte automáticamente en nota.

Construcción de criterios observables

Usa esta fórmula:

acción visible + contenido disciplinar + condición de calidad + autonomía esperada

Ejemplo de Matemática:

Representa una cantidad con material o dibujo, escribe el numeral correspondiente y explica cómo comprobó, sin copiar la representación de un par.

Ejemplo de Lenguaje:

Identifica una idea explícita, señala la parte del texto o imagen que la sostiene y la comunica oralmente o por escrito.

Decisiones posteriores

Si predomina el nivel 4

  • propón transferencia a un contexto nuevo;
  • compara estrategias o productos;
  • solicita justificación más precisa;
  • avanza sin llenar tiempo con repetición.

Si predomina el nivel 3

  • forma grupos breves por necesidad concreta;
  • entrega una pista o representación;
  • reduce gradualmente el apoyo;
  • solicita una nueva evidencia individual.

Si predomina el nivel 2

  • identifica si la barrera es conceptual, lingüística, sensorial, motriz o de consigna;
  • cambia ejemplo o representación;
  • modela nuevamente una decisión clave;
  • no cambies automáticamente a un OA inferior.

Si predomina el nivel 1

  • revisa asistencia, participación, accesibilidad y condiciones;
  • ofrece otra forma y otro momento para demostrar;
  • no registres “no sabe” cuando en realidad “no fue posible observar”.

Moderación entre docentes

Para mejorar consistencia:

  1. seleccionen tres evidencias anonimizadas;
  2. apliquen la rúbrica por separado;
  3. comparen qué criterio produjo diferencias;
  4. acuerden ejemplos frontera;
  5. documenten el ajuste sin publicar datos personales.

Límites

Esta rúbrica no diagnostica necesidades educativas, no determina promoción y no produce una calificación automática. Su finalidad es apoyar decisiones próximas y hacer visible la evidencia utilizada.
