Cada nivel debe pasar por el mismo contrato: desarrollo disciplinar, verificación automática, revisión humana documentada y comprobación visual del portal.

Criterio para declarar un nivel completo

Un nivel solo se declara desarrollado cuando todas sus clases tienen contenido específico y cumplen el contrato automatizado. Solo se declara revisado cuando existe evidencia humana disciplinar, pedagógica, documental, accesible y de derechos. Publicar archivos no sustituye ninguno de esos controles.
