Política de seguridad

No publiques secretos, datos personales ni documentos confidenciales en un issue. Reporta de

forma privada mediante Security → Report a vulnerability en GitHub e incluye la ruta afectada,

el impacto observado y una forma segura de reproducirlo.

Este repositorio no presta un servicio ni procesa datos de usuarios. Los riesgos principales son

la incorporación accidental de secretos, material no autorizado o reglas que den una falsa

sensación de cumplimiento.
