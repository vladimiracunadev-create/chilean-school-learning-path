Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Hoy aprenderé a pasar un algoritmo desde las palabras al seudocódigo y de ahí a un lenguaje de programación, Python, reconociendo qué instrucción corresponde a cuál.

Lo que ya debo saber. Ya uso listas, tablas y números en mi vida diaria, como una boleta, un horario o un registro de gastos. Sé que un algoritmo es una secuencia de pasos claros para resolver un problema.

Explicación

Un lenguaje de programación es un conjunto de reglas escritas para dar instrucciones a una computadora. Sus reglas de escritura se llaman sintaxis. Python es uno de esos lenguajes. Hoy no usamos computador: leemos el código y lo seguimos a mano, como lo haría un intérprete, que es el programa que ejecuta el código.

El proceso lógico va en tres escalones: primero el problema en palabras, luego el seudocódigo, que ordena los pasos sin reglas estrictas, y por último el código. Cada símbolo tiene su equivalente: la flecha ← se escribe = en Python, el signo × se escribe *, y «mostrar» se escribe print( ). Los textos van entre comillas y una línea que empieza con # es un comentario que no se ejecuta.

Cuidado con dos símbolos parecidos: = guarda un valor en una variable y == compara si dos valores son iguales. Un entorno de programación es el lugar donde se escribe y se ejecuta el código. Escribir primero el seudocódigo ayuda a revisar la lógica antes de preocuparse por la sintaxis.

Ejemplos resueltos paso a paso

Ejemplo 1. Leer el código

Problema: Con el código de la ficha, ¿qué muestra print(total)?

  1. precio = 1500 y cantidad = 3.
  2. total = precio * cantidad = 1500 × 3 = 4500.
  3. print(total) muestra ese valor.

Respuesta: 4500

Ejemplo 2. Traducir a Python

Problema: Traduce a Python: «descuento ← 200; neto ← total − descuento; mostrar neto».

  1. La flecha ← pasa a ser =.
  2. El signo − se escribe -.
  3. «Mostrar» pasa a ser print( ).

Respuesta: descuento = 200 / neto = total - descuento / print(neto)

Errores frecuentes y cómo reconocerlos

  • Error: Escribir 3 = cantidad, con el valor a la izquierda. Por qué ocurre: En Python el nombre de la variable va a la izquierda del =. Cómo corregirlo: Escribe cantidad = 3.
  • Error: Usar == para guardar un valor, como «total == precio * cantidad». Por qué ocurre: == compara; no guarda nada. Cómo corregirlo: Para guardar usa un solo =.

Explicación

Las repeticiones y las decisiones tienen su palabra en Python. «Mientras» se escribe while, «si» se escribe if y «si no» se escribe else. Después de la condición se escriben dos puntos. Las líneas que se repiten o que dependen de la condición van con sangría, es decir, corridas hacia la derecha.

También hay operadores de comparación: >, <, >=, <= y ==. Además, % entrega el resto de una división: 8 % 2 es 0 porque 8 se divide exacto entre 2. Para seguir el código a mano, haz una tabla de seguimiento con el valor de cada variable y lo que se muestra.

Hay dos clases de error. Un error de sintaxis rompe las reglas de escritura, como olvidar los dos puntos: el lenguaje no entiende la instrucción. Un error de lógica sí se entiende, pero hace algo distinto de lo que querías, como escribir > donde debía ir >=. Para encontrarlo, hay que probar casos.
