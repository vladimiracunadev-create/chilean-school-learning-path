Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a precisar qué es una potencia de exponente entero (positivo, cero o negativo), qué valores de x admite y cómo se comporta según su signo. Sirve para construir modelos de crecimiento y decrecimiento con f(x) = xⁿ.

Lo que ya debo saber. Sé calcular potencias de exponente natural. Sé que no se puede dividir por cero.

Explicación

Una función potencia de exponente entero tiene la forma f(x) = xⁿ, con n un número entero. Si n es positivo, xⁿ es el producto de x por sí mismo n veces. Si n = 0, x⁰ = 1 para todo x distinto de 0. Si el exponente es negativo, −m con m positivo, x⁻ᵐ = 1 ÷ xᵐ, que solo existe para x distinto de 0. Al dividir potencias de igual base se restan los exponentes: xᵃ ÷ xᵇ = xᵃ⁻ᵇ.

El exponente negativo no hace que el resultado sea negativo: es la idea de dividir. Por ejemplo, 2⁻³ = 1/2³ = 1/8, que es positivo. El signo del resultado depende de la base y de si el exponente es par o impar: (−2)³ = −8, (−2)⁴ = 16 y (−2)⁻³ = −1/8.

La paridad de n da simetrías. Si n es par, f(−x) = f(x) y la gráfica es simétrica respecto del eje vertical. Si n es impar, f(−x) = −f(x) y la gráfica es simétrica respecto del origen. Antes de usar una función potencia como modelo, hay que decir su dominio y qué representa x.

Ejemplos resueltos paso a paso

Ejemplo 1. Evaluar y dominio

Problema: Para f(x) = x⁻², calcula f(2), f(−2) y f(0).

  1. f(2) = 1/2² = 1/4.
  2. f(−2) = 1/(−2)² = 1/4, porque el exponente es par.
  3. f(0) = 1/0² no existe: 0 no está en el dominio.

Respuesta: f(2) = 1/4; f(−2) = 1/4; f(0) no existe

Ejemplo 2. Exponente impar

Problema: Para g(x) = x³, calcula g(−2) y g(2) y describe la simetría.

  1. g(2) = 8.
  2. g(−2) = (−2)³ = −8.
  3. Como g(−x) = −g(x), la gráfica es simétrica respecto del origen.

Respuesta: g(2) = 8; g(−2) = −8; simetría respecto del origen

Errores frecuentes y cómo reconocerlos

  • Error: Decir que 3⁻² = −9 porque «el exponente es negativo». Por qué ocurre: El exponente negativo indica dividir, no cambiar el signo. Cómo corregirlo: 3⁻² = 1/3² = 1/9.
  • Error: Calcular 2⁻³ = −6. Por qué ocurre: Se multiplicó la base por el exponente. Cómo corregirlo: 2⁻³ = 1/(2 · 2 · 2) = 1/8.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a representar una función potencia con una tabla y con una gráfica, y a describir si crece o decrece. Sirve para ver el mismo modelo de dos maneras y detectar errores en cualquiera de ellas.

Lo que ya debo saber. Sé evaluar xⁿ con exponentes enteros. Sé leer una tabla de valores y una gráfica.

Explicación

Una tabla de valores y una gráfica son dos representaciones de la misma función. En la tabla, ordenas valores de x y calculas f(x). En la gráfica, ubicas esos pares como puntos y los unes con una curva solo si el dominio lo permite. Si la tabla y la gráfica no coinciden, hay un error en una de las dos.

Para x positivo, f(x) = xⁿ con n positivo crece cuando x crece, y lo hace más rápido cuanto mayor es n. Con exponente negativo, como f(x) = x⁻ᵐ con m positivo, la función decrece cuando x crece: se acerca a 0 sin llegar a 0, y crece sin tope cuando x se acerca a 0 por la derecha. Por ejemplo, x⁻² pasa de 1 a 1/4, 1/9 y 1/16.

Un efecto útil: si x se duplica, xⁿ se multiplica por 2ⁿ. Para n = 2 se multiplica por 4; para n = −2 se multiplica por 1/4. Una potencia no es lo mismo que una exponencial: en x² la variable es la base y en 2ˣ la variable es el exponente. Sus valores se pueden cruzar, pero crecen de forma distinta.

Ejemplo 1. Tabla y comportamiento

  2. Los valores bajan a medida que x sube, pero siempre son positivos.

Respuesta: Es decreciente para x > 0 y se acerca a 0

Ejemplo 2. Potencia y exponencial

Problema: Compara x² y 2ˣ para x = 1, 2, 3, 4, 5.

  1. x²: 1, 4, 9, 16, 25. 2ˣ: 2, 4, 8, 16, 32.
  2. En x = 3 gana x² (9 contra 8); en x = 5 gana 2ˣ (32 contra 25).

Respuesta: Se cruzan, pero 2ˣ termina creciendo más rápido

Errores frecuentes y cómo reconocerlos

  • Error: Unir los puntos de y = x⁻¹ pasando por x = 0. Por qué ocurre: En x = 0 la función no está definida. Cómo corregirlo: Dibuja dos ramas separadas, una para x > 0 y otra para x < 0.
  • Error: Decir que x² y 2ˣ son la misma función. Por qué ocurre: En x² la variable es la base y en 2ˣ es el exponente. Cómo corregirlo: Calcula ambas en varios valores y compara.

Explicación

Las funciones seno y coseno se definen con la circunferencia de radio 1: para un ángulo x, el punto de la circunferencia es (cos x, sen x). Valores útiles: sen 0° = 0, sen 30° = 1/2, sen 90° = 1, sen 180° = 0, sen 270° = −1, cos 0° = 1, cos 90° = 0 y cos 180° = −1. Ambas funciones se repiten cada 360° (que equivalen a 2π radianes) y sus valores están entre −1 y 1.

Un modelo periódico general es y = D + A · sen(b · t). La amplitud A es la mitad de la distancia entre el máximo y el mínimo: A = (máx − mín) ÷ 2. El nivel medio D es el centro: D = (máx + mín) ÷ 2. Si un ciclo dura P unidades de tiempo, b = 360° ÷ P. Con coseno el modelo es igual, pero parte de su valor máximo en t = 0.

Para construir el modelo: lee el máximo, el mínimo y el período, calcula A, D y b, y comprueba con un valor conocido. Un modelo periódico solo sirve mientras el fenómeno se repita de forma regular; fuera de ese rango, o si cambian las condiciones, hay que revisarlo.

Un punto de la circunferencia de radio 1 tiene coordenadas (cos x, sen x). Como la distancia al centro es 1, el teorema de Pitágoras da la identidad fundamental: sen²x + cos²x = 1, válida para todo ángulo x. Con ella, si conoces uno de los valores y el cuadrante, puedes calcular el otro.

La simetría de la circunferencia da más relaciones: sen(−x) = −sen x, cos(−x) = cos x, sen(180° − x) = sen x, cos(180° − x) = −cos x, sen(180° + x) = −sen x y sen(x + 360°) = sen x. Valores de referencia: sen 30° = 1/2 y cos 60° = 1/2. Para ángulos grandes, resta vueltas de 360°.

Cuando uses una relación, justifícala con el dibujo: ubica el ángulo, marca el punto simétrico y compara coordenadas. Un solo ejemplo numérico no demuestra una identidad; la prueba usa la circunferencia o Pitágoras. Si dos valores dados no cumplen sen²x + cos²x = 1, no pueden ser del mismo ángulo.

Ejemplo 1. Calcular el coseno

Problema: Si sen x = 3/5 y x está en el primer cuadrante, ¿cuánto vale cos x?

  1. Uso sen²x + cos²x = 1: cos²x = 1 − 9/25 = 16/25.
  2. En el primer cuadrante el coseno es positivo.

Respuesta: cos x = 4/5

Ejemplo 2. Usar una simetría

Problema: Sabiendo que sen 30° = 1/2, calcula sen 150°.

  1. 150° = 180° − 30°.
  2. sen(180° − x) = sen x, entonces sen 150° = sen 30°.

Respuesta: 1/2

Errores frecuentes y cómo reconocerlos

  • Error: Escribir sen²x + cos²x = sen x + cos x. Por qué ocurre: Se confunde el cuadrado de un valor con el valor. Cómo corregirlo: La identidad suma los cuadrados y da 1.
  • Error: Decir que cos x es positivo en el segundo cuadrante. Por qué ocurre: En el segundo cuadrante el punto está a la izquierda del eje vertical. Cómo corregirlo: En el segundo cuadrante el coseno es negativo y el seno positivo.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a comprobar un modelo con datos, a comparar dos modelos posibles y a contrastarlo con información de internet. Sirve para decidir qué modelo explica mejor una situación y con qué límites.

Lo que ya debo saber. Sé construir modelos con potencias y con seno o coseno. Sé evaluar una fuente de información.

Explicación

Para comprobar un modelo, calcula lo que predice para varios valores y compara con los datos. El error absoluto es |valor real − valor predicho|. El error relativo es el error absoluto dividido por el valor real o por el predicho, en porcentaje. Un buen modelo tiene errores pequeños en todos los datos y no solo en algunos.

Para elegir entre modelos, mira primero la forma de los datos. Si los datos se repiten con regularidad, piensa en un modelo periódico con seno o coseno. Si disminuyen o aumentan sin repetirse, y dependen de una distancia o de una cantidad, piensa en una potencia. Compara los errores totales y revisa si el modelo tiene sentido fuera de los datos.

Cuando uses información de internet, verifica quién publica los datos, cuándo y cómo se midieron, y contrasta con una segunda fuente independiente. Un modelo con buen ajuste en tres datos puede fallar con otros. Comunica siempre el modelo, el dominio donde vale, los errores observados y los límites.
