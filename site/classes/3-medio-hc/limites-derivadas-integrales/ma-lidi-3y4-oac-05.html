Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a ver la integral como el área entre una gráfica y el eje horizontal, calculándola con figuras conocidas y escribiéndola con la notación de integral. Sirve para obtener cantidades acumuladas, como distancia o volumen.

Lo que ya debo saber. Sé calcular áreas de rectángulos, triángulos y trapecios. Sé leer una gráfica de velocidad contra tiempo. Sé que distancia = rapidez × tiempo si la rapidez es constante.

Explicación

El área bajo la curva de una función f entre x = a y x = b, cuando f no es negativa, es la región entre la gráfica y el eje horizontal. Esa área se llama integral definida de f entre a y b y se escribe ∫ₐᵇ f(x) dx. Si la gráfica es una figura conocida, el área se calcula con fórmulas: rectángulo (base por altura), triángulo (base por altura dividido por 2) y trapecio ((base mayor + base menor) por altura dividido por 2).

El área tiene un significado según las unidades de los ejes. Si v está en metros por segundo y t en segundos, el área tiene unidades de metros por segundo por segundo, es decir, metros: la distancia recorrida. Para v(t) = 4 entre 0 y 5, el área es el rectángulo 4·5 = 20 m. Para u(t) = 2t entre 0 y 6, es un triángulo de base 6 y altura 12: 6·12/2 = 36 m.

Para w(t) = 3 + t entre 0 y 4, la región es un trapecio con lados paralelos de 3 y 7 y altura 4: (3 + 7)·4/2 = 20. En general, el área acumula lo que la función aporta en cada instante. Cuando la función cambia de forma que no es una figura simple, se necesita aproximar o usar otras herramientas, que se verán en las próximas clases.

Ejemplos resueltos paso a paso

Ejemplo 1. Área de un rectángulo como distancia

Problema: Una bicicleta de ejemplo va a 5 m/s entre t = 0 y t = 8 s. ¿Qué distancia recorre?

  1. La gráfica de velocidad es un rectángulo de base 8 y altura 5.
  2. Área = 8·5 = 40, con unidades m/s por s, es decir, metros.

Respuesta: Recorre 40 m

Ejemplo 2. Área de un triángulo

Problema: Para y(x) = x entre 0 y 10, calcula el área bajo la curva.

  1. La región es un triángulo de base 10 y altura 10.
  2. Área = 10·10/2 = 50.

Respuesta: El área es 50, es decir, ∫₀¹⁰ x dx = 50

Errores frecuentes y cómo reconocerlos

  • Error: Calcular el área de un triángulo como base por altura sin dividir por 2. Por qué ocurre: Se confunde con el rectángulo. Cómo corregirlo: Recuerda que un triángulo ocupa la mitad del rectángulo.
  • Error: Dar el área sin unidad o con unidad equivocada. Por qué ocurre: No se interpreta el significado de los ejes. Cómo corregirlo: Multiplica las unidades: m/s por s da m.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a aproximar el área bajo una curva con rectángulos, usando una tabla y una gráfica, y a distinguir la aproximación por la izquierda de la de por la derecha. Sirve para estimar áreas cuando la región no es una figura conocida.

Lo que ya debo saber. Sé calcular áreas de rectángulos. Sé evaluar f(x) = x². Sé sumar varios términos con ayuda de la calculadora.

Explicación

Cuando la región bajo una curva no es una figura conocida, se aproxima con rectángulos de igual ancho. El ancho es Δx = (b − a)/n, donde n es el número de rectángulos. Con la función x² entre 0 y 4 y n = 4, el ancho es Δx = 1. La suma de las áreas de los rectángulos aproxima el área bajo la curva.

En la suma izquierda, la altura de cada rectángulo es el valor de f en el extremo izquierdo de su base: f(0), f(1), f(2) y f(3). Su suma es 1·(0 + 1 + 4 + 9) = 14. En la suma derecha se usa el extremo derecho: f(1), f(2), f(3) y f(4), con suma 1·(1 + 4 + 9 + 16) = 30. Como f es creciente, la izquierda queda por debajo del área real y la derecha por encima.

Por eso el área real está entre 14 y 30. Con n = 2 (Δx = 2), la suma izquierda es 2·(0 + 4) = 8 y la derecha es 2·(4 + 16) = 40: la distancia entre ellas es mayor. Cuantos más rectángulos, más cerca queda la aproximación. Una tabla con columnas x, f(x) y área de cada rectángulo ordena el trabajo.

Errores frecuentes y cómo reconocerlos

  • Error: Usar un ancho distinto para cada rectángulo. Por qué ocurre: Se confunde la altura con el ancho. Cómo corregirlo: Calcula una vez Δx = (b − a)/n y úsalo en todos.
  • Error: Sumar las alturas sin multiplicar por Δx. Por qué ocurre: Se olvida que el área es altura por ancho. Cómo corregirlo: Multiplica la suma de alturas por Δx.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a mejorar la aproximación con más rectángulos y a ver la integral definida como el límite de las sumas de rectángulos. Sirve para entender por qué la integral da el área exacta.

Lo que ya debo saber. Sé calcular sumas izquierda y derecha. Sé qué es un límite. Sé calcular el área de un triángulo.

Explicación

Si se duplica el número de rectángulos, cada uno es más delgado y la aproximación mejora. Con f(x) = x en [0, 4]: con n = 4 las sumas son 6 y 10; con n = 8, son 7 y 9; con n = 16, son 7,5 y 8,5. La distancia entre las dos sumas baja de 4 a 2 y a 1: se reduce a la mitad cada vez que se duplica n.

Las dos sumas se acercan a un mismo valor, 8, que es el área exacta del triángulo (base 4 por altura 4 dividido por 2). Ese valor común es el límite de las sumas cuando n tiende a infinito. Para funciones continuas, el límite de las sumas izquierda y derecha existe y es el mismo; ese número es la integral definida ∫ₐᵇ f(x) dx.

La notación ∫ₐᵇ f(x) dx recuerda que es una suma de productos f(x)·Δx cuando Δx se hace muy pequeño: el símbolo ∫ es una S alargada, de «suma». Así, ∫₀⁴ x dx = 8. Con tablas y herramientas digitales se pueden calcular sumas con muchos rectángulos, pero el valor exacto de la integral se confirma por otras vías, como una figura geométrica conocida.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a calcular integrales definidas de polinomios sencillos con una antiderivada y a comprobar el resultado con áreas conocidas. Sirve para obtener el área exacta sin sumar muchos rectángulos.

Lo que ya debo saber. Sé derivar polinomios. Sé que la integral es el área bajo la curva. Sé evaluar funciones en un punto.

Explicación

Una antiderivada de f es una función F cuya derivada es f. Por ejemplo, x² es una antiderivada de 2x, porque la derivada de x² es 2x. También lo es x² + 5, porque la derivada de una constante es 0. Para xⁿ, una antiderivada es xⁿ⁺¹ dividido por n + 1; para una constante k, es kx. Siempre se puede comprobar derivando.

El teorema fundamental del cálculo une derivadas e integrales: si F es una antiderivada de f, entonces ∫ₐᵇ f(x) dx = F(b) − F(a). Con f(x) = 2x entre 0 y 4: F(x) = x², F(4) − F(0) = 16 − 0 = 16. Ese resultado coincide con el área del triángulo bajo y = 2x, de base 4 y altura 8 (4·8/2 = 16). La constante que se agregue a F se cancela en la resta.

Con g(x) = 3x² entre 0 y 3: G(x) = x³ y G(3) − G(0) = 27 − 0 = 27. Con x² entre 0 y 3: una antiderivada es x³/3, y el resultado es 27/3 − 0 = 9. Para una suma de términos se usa una antiderivada de cada término. Este método da el valor exacto al que tienden las sumas de rectángulos y se verifica con áreas de figuras cuando la gráfica es una recta.

Errores frecuentes y cómo reconocerlos

  • Error: Calcular F(a) − F(b) en lugar de F(b) − F(a). Por qué ocurre: Se invierte el orden de los límites. Cómo corregirlo: Resta siempre el valor en el límite inferior al del superior.
  • Error: Decir que la antiderivada de x² es 2x. Por qué ocurre: Se deriva en vez de integrar. Cómo corregirlo: Sube el exponente y divide por el nuevo exponente: x³/3.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a comparar aproximaciones con el valor exacto de una integral, a calcular el error y a entender el área con signo cuando la gráfica queda bajo el eje. Sirve para evaluar si una estimación es confiable.

Lo que ya debo saber. Sé calcular sumas izquierda y derecha. Sé calcular una integral con antiderivada. Sé el significado de área con unidades.

Explicación

El error de una aproximación es la diferencia entre el valor exacto y el estimado. Con f(x) = x² en [0, 3], el área exacta es 9. Con n = 3, la suma izquierda 5 se equivoca en 4 y la derecha 14 en 5. Con n = 6, la izquierda 6,875 se equivoca en 2,125 y la derecha 11,375 en 2,375. Al doblar n los errores bajan, lo que confirma que las sumas se acercan al valor exacto.

Un buen criterio es comprobar que el área exacta queda entre la suma izquierda y la derecha cuando la función es creciente, y que el promedio de ambas es una mejor estimación: (5 + 14)/2 = 9,5 y (6,875 + 11,375)/2 = 9,125, cada vez más cerca de 9. Compararlos con el valor exacto permite decidir si una estimación sirve o necesita más rectángulos.

Si la función es negativa sobre un tramo, la integral cuenta esa parte con signo negativo. Con s(x) = x − 1 entre 0 y 2, los dos triángulos (uno bajo el eje y otro sobre él, cada uno de área 1/2) se compensan y la integral es F(2) − F(0) = 0. El área total sin signo es 1/2 + 1/2 = 1. Por eso hay que distinguir integral (con signo) y área total (sin signo).

Errores frecuentes y cómo reconocerlos

  • Error: Interpretar una integral negativa como un error. Por qué ocurre: Se ignora el signo del área. Cómo corregirlo: Una integral negativa indica que la región está bajo el eje.
  • Error: Dar por exacta una suma con pocos rectángulos. Por qué ocurre: Se confunde estimación con valor exacto. Cómo corregirlo: Compara con el valor exacto o con n mayor antes de concluir.

Lo que aprenderé y para qué sirve. Aprenderé a modelar una situación con una integral como área bajo la curva, a interpretarla con unidades y a decidir si el modelo hay que ajustarlo con datos reales. Sirve para estimar acumulados en ciencias y en la vida diaria.

Lo que ya debo saber. Sé calcular áreas bajo gráficas con figuras y con integrales. Sé estimar con sumas de rectángulos. Sé interpretar unidades.

Explicación

Una integral sirve para acumular. Si q(t) es un caudal en litros por minuto, el área bajo q entre dos tiempos es el volumen que pasó, en litros. Para q(t) = 12 − 2t entre 0 y 6, la región es un triángulo de base 6 y altura 12, con área 6·12/2 = 36 L. Con antiderivada: F(6) − F(0) = (72 − 36) − 0 = 36 L. Ambos métodos coinciden.

Con sumas de rectángulos (Δt = 2), la izquierda da 2·(12 + 8 + 4) = 48 L y la derecha 2·(8 + 4 + 0) = 24 L. Como q decrece, la izquierda sobreestima y la derecha subestima el volumen 36. Con n = 6 (Δt = 1) la izquierda da 42 y la derecha 30: más cerca de 36. Una hoja de cálculo permite repetir esas sumas con muchos rectángulos.

Un modelo hay que contrastarlo con datos. Si el recipiente real recibió 34 L y el modelo da 36 L, el error es 2 L: se puede aceptar si la tolerancia lo permite, o ajustar una constante, por ejemplo la pendiente. También hay que declarar el rango de validez: q(t) = 12 − 2t solo sirve hasta t = 6, porque después daría caudales negativos, algo que en esta llave no tiene sentido.

Autoevaluación
  1. E1 En Matemática: ¿qué representa el área bajo la curva de una tasa?
  2. E2 ¿Qué es el rango de validez de un modelo?
  3. E3 Si el modelo da 36 y la medición es 34, ¿cuánto vale el error?

Actividad abierta. Se modela el consumo de agua de una familia de ejemplo con c(t) = 5 + t litros por minuto durante una ducha de 4 minutos. Calcula el total con la antiderivada 5t + t²/2 y con el área del trapecio, interpreta el resultado con unidades, y compáralo con una medición de ejemplo de 28 litros decidiendo si ajustarías el modelo.

Solucionario razonado y pauta de la actividad abierta
  • R1. 12. Se reemplaza t por 0. Cálculo: 12 − 2 × 0 = 12.
  • R2. 6. Se reemplaza t por 3. Cálculo: 12 − 2 × 3 = 6.
  • R3. B) Litros. L/min multiplicado por min da L.
  • C1. 32 litros. La región bajo q entre 0 y 4 es un trapecio. Cálculo: (12 + 4) × 4 ÷ 2 = 32.
  • C2. 35 litros. F(5) = 60 − 25 y F(0) = 0. Cálculo: (12 × 5 − 5 × 5) − (12 × 0 − 0 × 0) = 35.
  • C3. 40 litros. Alturas q(0) y q(2), ancho 2. Cálculo: 2 × (12 + 8) = 40.
  • A1. 24 litros. Alturas q(2) y q(4), ancho 2. Cálculo: 2 × (8 + 4) = 24.
  • A2. C) La izquierda sobreestima (40) y la derecha subestima (24). En una función decreciente el extremo izquierdo es el más alto.
  • A3. 21 litros. Se evalúa F en 4 y se resta F en 1. Cálculo: (12 × 4 − 4 × 4) − (12 × 1 − 1 × 1) = 21.
  • Z1. A) Aceptar el modelo con error de 2 L y ajustarlo si el error se repite o supera la tolerancia. Un error pequeño no invalida el modelo, pero conviene revisarlo con más mediciones.
  • Z2. Hasta t = 6, porque después daría caudal negativo. q(6) = 0 y para t mayor el valor resulta negativo.
  • D1. 36 litros. Cada altura es q(0), q(1), q(2) y q(3), con ancho 1. Cálculo: 12 + 10 + 8 + 6 = 36.
  • D2. A) Se acerca al volumen exacto de 32. 36 está más cerca de 32 que 40.
  • S1. 50 unidades. El total acumulado es el área bajo la tasa de producción. Cálculo: 5 × 20 ÷ 2 = 50.
  • E1. El total acumulado, como litros o unidades. La tasa por el tiempo da la cantidad acumulada.
  • E2. Los valores de la variable donde el modelo sirve. Fuera de él puede dar resultados sin sentido.
  • E3. 2. Es la diferencia entre el modelo y la medición. Cálculo: 36 − 34 = 2.

Ejemplo de respuesta: Antiderivada: F(4) − F(0) = (20 + 8) − 0 = 28. Trapecio: (5 + 9)·4/2 = 28. Total: 28 litros de agua. La medición de 28 litros coincide con el modelo, así que no hace falta ajustarlo; igual conviene probarlo con más mediciones.

Criterios: calcula el total por dos vías; interpreta con unidades; decide si ajustar con un criterio.

Evidencias aceptables: hoja con dos cálculos, interpretación y decisión.

Errores que conviene detectar: omitir las unidades; no comparar con la medición; usar el modelo fuera del rango sin avisar.

Retroalimentación constructiva: Pregunta: «¿qué significa el 28?». Debe decir litros acumulados en 4 minutos.

Refuerzo. Con q(t) = 12 − 2t, calcula el volumen entre t = 2 y t = 6 con F(t) = 12t − t².

Profundización. Propón un modelo de caudal que no pueda ser negativo en todo el intervalo de interés y explica cómo cambia el rango de validez.

Apoyo: Reduce cantidad de datos, ofrece una representación equivalente y una lista de condiciones; conserva la decisión matemática y no completa el procedimiento.

Profundización: Cambia un parámetro, restricción o representación, formula una conjetura y determina si el argumento todavía se sostiene.
