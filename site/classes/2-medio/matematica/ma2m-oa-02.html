Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé qué son las raíces enésimas (cúbicas, cuartas, quintas…), cuándo existen y entre qué enteros se ubican. Sirve para medir aristas de cubos y para entender las potencias de exponente racional.

Lo que ya debo saber. Sé calcular raíces cuadradas. Sé calcular potencias con exponente entero.

Explicación

La raíz enésima de un número a, escrita ⁿ√a, es el número que elevado a n da a. Por ejemplo ³√27 = 3 porque 3³ = 27, y ⁴√16 = 2 porque 2⁴ = 16. El número n se llama índice. En la raíz cuadrada el índice 2 no se escribe.

Si el índice es impar, el radicando puede ser negativo: ³√(−8) = −2 porque (−2)³ = −8. Si el índice es par, el radicando negativo no tiene raíz real, porque ningún número real elevado a una potencia par da negativo. Por eso ⁴√(−16) no es un número real.

Para ubicar una raíz enésima en la recta, busca las potencias enésimas de enteros que la rodean. Como 3³ = 27 y 4³ = 64, el número ³√50 está entre 3 y 4. Comprueba elevando tu estimación a la potencia n: 3,7³ = 50,653, muy cerca de 50.

Ejemplos resueltos paso a paso

Ejemplo 1. Ubicar una raíz cúbica

Problema: ¿Entre qué enteros está ³√50 y cuál es una estimación con un decimal?

  1. Busco cubos cercanos: 3³ = 27 y 4³ = 64.
  2. Como 27 < 50 < 64, la raíz está entre 3 y 4.
  3. Pruebo 3,7³ = 50,653: es un poco más que 50, así que 3,7 es una buena estimación.

Respuesta: Entre 3 y 4; ³√50 ≈ 3,7

Ejemplo 2. Índice par y radicando negativo

Problema: ¿Existe ⁴√(−81) como número real? ¿Y ⁴√81?

  1. Un número real elevado a 4 siempre es positivo o cero.
  2. Por eso no hay número real que elevado a 4 dé −81.
  3. En cambio, 3⁴ = 81.

Respuesta: ⁴√(−81) no es real; ⁴√81 = 3

Errores frecuentes y cómo reconocerlos

  • Error: Calcular ³√27 = 9 porque 27 ÷ 3 = 9. Por qué ocurre: Se confunde la raíz con dividir por el índice. Cómo corregirlo: Comprueba con la potencia: 9³ = 729, no 27. La respuesta es 3 porque 3 · 3 · 3 = 27.
  • Error: Decir que ³√(−8) no existe porque el radicando es negativo. Por qué ocurre: Se aplica la regla de las raíces cuadradas a un índice impar. Cómo corregirlo: (−2)³ = −8, entonces ³√(−8) = −2.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a pasar de una raíz enésima a una potencia de exponente racional y de vuelta. Sirve para calcular y comparar valores usando las dos escrituras.

Lo que ya debo saber. Sé qué es una raíz enésima. Sé que una raíz cuadrada y una raíz cúbica deshacen una potencia.

Explicación

Una raíz se puede escribir como potencia con exponente fraccionario: a^(1/n) = ⁿ√a. Así 25^(1/2) = √25 = 5 y 27^(1/3) = ³√27 = 3. El denominador de la fracción es el índice de la raíz.

Si el numerador no es 1: a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ. Por ejemplo, 8^(2/3) = (³√8)² = 2² = 4, y 16^(3/4) = (⁴√16)³ = 2³ = 8. Conviene sacar primero la raíz porque da números pequeños. Se usa base positiva.

En la recta numérica, si la base es mayor que 1, un exponente mayor da un valor mayor: 2^(1/3) < 2^(1/2) porque 1/3 < 1/2. Si la base está entre 0 y 1 ocurre lo contrario. Para comparar, escribe ambos valores como raíces y estima cada uno.

Ejemplos resueltos paso a paso

Ejemplo 1. De potencia a raíz y valor

Problema: Calcula 32^(2/5).

  1. El denominador 5 es el índice: 32^(2/5) = (⁵√32)².
  2. ⁵√32 = 2 porque 2⁵ = 32.
  3. Elevo al cuadrado: 2² = 4.

Respuesta: 4

Ejemplo 2. De raíz a potencia

Problema: Escribe ⁴√(7³) como potencia de exponente racional.

  1. El índice 4 va al denominador.
  2. El exponente 3 del radicando va al numerador.

Respuesta: 7^(3/4)

Errores frecuentes y cómo reconocerlos

  • Error: Calcular 8^(2/3) = 8² ÷ 3 = 64/3. Por qué ocurre: Se trata el exponente fraccionario como una división del resultado. Cómo corregirlo: El denominador es el índice: primero ³√8 = 2 y luego 2² = 4.
  • Error: Calcular 9^(1/2) = 9 ÷ 2 = 4,5. Por qué ocurre: Se confunde «elevar a 1/2» con «dividir por 2». Cómo corregirlo: Elevar a 1/2 es sacar raíz cuadrada: √9 = 3.

Explicación

Las propiedades de las potencias de exponente entero siguen valiendo con exponente racional, si la base es positiva. Al multiplicar potencias de igual base se suman los exponentes: aᵖ · aᵠ = a^(p+q). Al dividir se restan: aᵖ ÷ aᵠ = a^(p−q).

Para elevar una potencia a otra se multiplican los exponentes: (aᵖ)ᵠ = a^(p·q). Para un producto vale (a · b)ᵖ = aᵖ · bᵖ. Un exponente negativo invierte la base: a^(−p) = 1/aᵖ. Así 16^(−1/4) = 1/16^(1/4) = 1/2.

Estas propiedades permiten operar raíces de distinto índice. Como √2 = 2^(1/2) y ³√2 = 2^(1/3), el producto √2 · ³√2 = 2^(1/2 + 1/3) = 2^(5/6) = ⁶√(2⁵) = ⁶√32. Calcula la suma de fracciones con denominador común.

Lo que ya debo saber. Sé calcular potencias con exponente entero. Sé que una potencia de base positiva es positiva.

Explicación

El logaritmo en base b de un número a es el exponente al que hay que elevar b para obtener a. Se escribe log_b a = c y significa lo mismo que bᶜ = a. Por ejemplo, log₂ 8 = 3 porque 2³ = 8. Se pide b > 0, b distinto de 1, y a > 0.

Si no se escribe la base, se entiende base 10: log 1.000 = 3 porque 10³ = 1.000. Algunos valores siempre valen lo mismo: log_b 1 = 0 porque b⁰ = 1, y log_b b = 1 porque b¹ = b. Con exponentes negativos: log₅(1/25) = −2 porque 5⁻² = 1/25.

Un logaritmo también puede ser fraccionario, y ahí aparecen las raíces: log₉ 3 = 1/2 porque 9^(1/2) = 3. No existe el logaritmo de 0 ni de un número negativo, porque una potencia de base positiva nunca da 0 ni negativo. Para ubicar un logaritmo, mira entre qué potencias queda el número.

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé las propiedades de los logaritmos y las usaré para resolver problemas con potencias, raíces y logaritmos. Sirve para hallar exponentes y comparar crecimientos.

Lo que ya debo saber. Sé la definición de logaritmo. Sé las propiedades de las potencias.

Explicación

Como los logaritmos son exponentes, heredan las reglas de las potencias. El logaritmo de un producto es la suma de logaritmos: log_b(x · y) = log_b x + log_b y. El de un cociente es la resta: log_b(x ÷ y) = log_b x − log_b y. Por ejemplo, log₂ 4 + log₂ 8 = 2 + 3 = 5 = log₂ 32.

El logaritmo de una potencia baja el exponente: log_b(xⁿ) = n · log_b x. Por ejemplo, log₃ 9³ = 3 · log₃ 9 = 3 · 2 = 6. Cuidado: log_b(x + y) no es log_b x + log_b y. Estas propiedades valen para x e y positivos.

Para resolver una ecuación exponencial como 3ˣ = 243, escribe ambos lados con la misma base (243 = 3⁵) o usa x = log₃ 243 = 5. Si la base no queda igual, ubica el resultado entre dos enteros o usa un dato dado, como log 2 ≈ 0,30. Con ese dato, log 500 = log(1.000 ÷ 2) = 3 − 0,30 = 2,70.
