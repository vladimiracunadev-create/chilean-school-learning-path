Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a escribir con letras y números relaciones que se dicen con palabras, como «el doble de un número más 7». Sirve para describir reglas, precios y medidas que cambian.

Lo que ya debo saber. Sé operar con números naturales y enteros. Sé qué significan «doble», «triple», «mitad», «más que» y «menos que».

Explicación

Una variable es una letra que representa un número que puede cambiar, como n, x o m. Una expresión algebraica combina números, letras y operaciones. En el álgebra se omite el signo de multiplicar entre un número y una letra: 2 · n se escribe 2n. Así, «el doble de n» es 2n, «el triple de x» es 3x y «la mitad de m» es m/2.

Para traducir una frase, busca las palabras clave. «Más», «aumentado en» y «suma» llevan +. «Menos», «disminuido en» y «diferencia» llevan −. Cuidado con el orden: «5 menos que x» se escribe x − 5, no 5 − x, porque se le quitan 5 a x. Y no es lo mismo «el doble de n, más 3», que se escribe 2n + 3, que «el doble de (n más 3)», que se escribe 2(n + 3).

Una expresión sirve para muchos casos. Si una entrada cuesta $3.500, el costo de n entradas es 3.500n. Para saber el costo de 4 entradas se reemplaza n por 4: 3.500 · 4 = 14.000. Reemplazar la letra por un número se llama evaluar o sustituir. Siempre indica qué significa la letra antes de usarla.

Ejemplos resueltos paso a paso

Ejemplo 1. Traducir una frase

Problema: Escribe en lenguaje algebraico: «el doble de un número, aumentado en 7».

  1. Llamo n al número. El doble de n es 2n.
  2. Aumentado en 7 significa sumar 7: 2n + 7.

Respuesta: 2n + 7

Ejemplo 2. Costo de varias entradas

Problema: Una entrada de ejemplo cuesta $3.500. Escribe el costo de n entradas y calcula el de 4 entradas.

  1. El costo es 3.500 por cada entrada: 3.500n.
  2. Sustituyo n = 4: 3.500 · 4 = 14.000.

Respuesta: 3.500n; $14.000

Errores frecuentes y cómo reconocerlos

  • Error: Escribir «5 menos que x» como 5 − x. Por qué ocurre: Se mantuvo el orden en que aparecen las palabras. Cómo corregirlo: «5 menos que x» es x − 5. Con x = 8: 5 menos que 8 es 3 = 8 − 5.
  • Error: Escribir «el doble de n más 3» como 2(n + 3). Por qué ocurre: Se agrupó todo dentro del doble. Cómo corregirlo: El doble se aplica solo a n: 2n + 3.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a descubrir la regla de un patrón de números o de figuras y a escribirla con una letra. Sirve para predecir cuántos elementos habrá en una figura lejana sin dibujarla.

Lo que ya debo saber. Sé continuar secuencias de números. Sé escribir expresiones con letras.

Explicación

Un patrón es una secuencia que sigue una regla. En 5, 8, 11, 14… cada número sube 3. La posición se llama n (n = 1, 2, 3…) y el valor es el término. Cuando la diferencia es constante, la regla tiene la forma dn + c, donde d es la diferencia. Aquí d = 3 y la regla es 3n + 2, porque para n = 1 se obtiene 3 + 2 = 5.

Para encontrar la regla: calcula la diferencia entre términos seguidos (d), multiplica d por la posición y ajusta con un número para llegar al primer término. Comprueba con otro término: con n = 4, 3 · 4 + 2 = 14. Si la regla funciona en todos, es correcta. Con una regla puedes predecir el término de cualquier posición, como el 20, sin escribirlos todos.

Los patrones también aparecen en figuras. Si la figura 1 tiene 4 palitos, la figura 2 tiene 7 y la figura 3 tiene 10, cada figura agrega 3 palitos: la regla es 3n + 1. Un patrón puede decir cuántas piezas necesitas para la figura 50. Para decidir si un número es término del patrón, plantea la regla igual a ese número y mira si la posición sale un natural.

Ejemplos resueltos paso a paso

Ejemplo 1. Regla de una secuencia

Problema: Encuentra la regla de 5, 8, 11, 14…

  1. La diferencia es 3, así que la regla empieza con 3n.
  2. Para n = 1 necesito 5, y 3 · 1 = 3, falta 2: la regla es 3n + 2. Compruebo con n = 4: 14.

Respuesta: 3n + 2

Ejemplo 2. Patrón con figuras

Problema: Una figura de ejemplo tiene 4 palitos si n = 1, 7 si n = 2 y 10 si n = 3. ¿Cuántos palitos tiene con n = 20?

  1. Cada figura agrega 3 palitos: regla 3n + 1.
  2. Con n = 20: 3 · 20 + 1 = 61.

Respuesta: 61 palitos

Errores frecuentes y cómo reconocerlos

  • Error: Decir que la regla de 5, 9, 13, 17 es 5n. Por qué ocurre: Se miró solo el primer término. Cómo corregirlo: La diferencia es 4, la regla es 4n + 1. Con n = 2, 4 · 2 + 1 = 9.
  • Error: Decir que 50 es un término de 4n + 1 porque «está cerca de 49». Por qué ocurre: No se comprobó con la regla. Cómo corregirlo: 4n + 1 = 50 daría n = 49/4, que no es natural. No es término.

Lo que aprenderé y para qué sirve. Aprenderé a escribir con letras propiedades que valen para todos los números, como «sumar en cualquier orden da lo mismo». Sirve para explicar por qué un cálculo siempre funciona.

Lo que ya debo saber. Sé usar letras para representar números. Conozco el orden de las operaciones.

Explicación

Con letras se pueden escribir propiedades que valen para cualquier número. La propiedad conmutativa de la suma dice que el orden no cambia el resultado: a + b = b + a. En la multiplicación, a · b = b · a. La propiedad asociativa dice que da lo mismo agrupar de distinta forma: (a + b) + c = a + (b + c). El cero y el uno son neutros: a + 0 = a y a · 1 = a.

La propiedad distributiva une la suma y la multiplicación: a(b + c) = ab + ac. Por ejemplo, 4(5 + 2) = 4 · 5 + 4 · 2 = 28. Con letras también se describen familias de números: un número par es 2n (si n es entero), un número impar es 2n + 1 y el sucesor de n es n + 1. Dos números consecutivos son n y n + 1.

Un ejemplo con números no demuestra que una propiedad siempre se cumple, pero un solo contraejemplo muestra que no es verdadera. Por ejemplo, a − b = b − a es falsa: con a = 5 y b = 2, da 3 y −3. Para probar que algo se cumple siempre se usa la letra. Cuando una propiedad se cumple, la letra se puede reemplazar por cualquier número.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé a construir ecuaciones a partir de situaciones y a comprobar si un número es solución. Sirve para encontrar valores desconocidos en problemas de dinero, edades y medidas.

Lo que ya debo saber. Sé escribir expresiones con letras. Sé evaluar una expresión.

Explicación

Una ecuación es una igualdad que tiene una incógnita, es decir, un valor desconocido que se representa con una letra. Por ejemplo, x + 7 = 15 dice: «un número más 7 es 15». La solución es el valor de la letra que hace verdadera la igualdad. Aquí x = 8, porque 8 + 7 = 15.

Para construir una ecuación, define qué representa la letra, escribe una expresión para cada lado y une con un signo igual. Si 3 cuadernos iguales y un lápiz de $400 cuestan $3.100, y c es el precio de un cuaderno, la ecuación es 3c + 400 = 3.100. Para resolverla se deshace cada operación: 3.100 − 400 = 2.700 y 2.700 ÷ 3 = 900.

Para validar, sustituye el valor encontrado en la ecuación original. Si los dos lados dan el mismo número, es solución. Con c = 900: 3 · 900 + 400 = 3.100. También sirve para revisar si un valor dado es o no es solución. Si los lados dan números distintos, ese valor no es solución.

validarcomprobar una solución sustituyéndola
igualdaddos expresiones con el mismo valor unidas por =

Ejemplo 1. Plantear y validar

  2. Valido: 8 + 7 = 15, se cumple.

Respuesta: x = 8

  2. Divido entre 3: c = 900. Valido: 3 · 900 + 400 = 3.100.

Respuesta: $900

Errores frecuentes y cómo reconocerlos

  • Error: Plantear «el doble de un número menos 5 es 11» como 2(x − 5) = 11. Por qué ocurre: Se aplicó el doble al resultado de restar. Cómo corregirlo: El doble de x es 2x, y luego se resta 5: 2x − 5 = 11, con x = 8.
  • Error: Dar x = 5 como solución de 3x − 2 = 10 sin comprobar. Por qué ocurre: No se sustituyó el valor. Cómo corregirlo: 3 · 5 − 2 = 13, que no es 10: x = 5 no es solución. La solución es x = 4.

  3. C3 Escribe la ecuación: «el triple de un número, disminuido en 4, es 20».
Aplicación
  1. A1 Dos helados iguales y un jugo de $700 cuestan $3.500 en total. Plantea la ecuación con h como precio de un helado y resuélvela.
  2. A2 Una caja tiene n lápices y hay 5 lápices sueltos aparte. En total hay 29 lápices. ¿Cuántos lápices hay en la caja?
  3. A3 Diego tiene $4.000 ahorrados y suma $1.500 cada semana. ¿En cuántas semanas tendrá $13.000?
Razonamiento y análisis
  1. Z1 Eva dice que x = 9 es solución de 2x + 3 = 15. ¿Es cierto?
  2. Z2 Ana plantea «el doble de un número, menos 5, es 11» como 2(x − 5) = 11. ¿Está bien planteada? Si no, escribe la ecuación correcta.
Desafío
  1. D1 La suma de dos números consecutivos es 31. Si el menor es n, plantea la ecuación y encuentra los números.
  2. D2 Un triángulo isósceles de ejemplo tiene dos lados iguales de x cm y la base mide x + 2 cm. Su perímetro es 26 cm. ¿Cuánto mide cada lado igual?
Situaciones auténticas
  1. S1 Un viaje en taxi de ejemplo cuesta $1.000 fijos más $300 por kilómetro. Si un viaje costó $3.400, ¿cuántos kilómetros fueron?
Autoevaluación
  1. E1 ¿Es x = 2 solución de 5x − 1 = 9?
  2. E2 Resuelve x + 12 = 20.
  3. E3 Escribe la ecuación: «la mitad de un número es 6».

Actividad abierta. Lee esta situación de ejemplo: «En una feria, Sofía compró 4 entradas iguales y pagó además $1.200 por estacionamiento. En total pagó $9.200». (a) Define la letra y escribe la ecuación. (b) Resuélvela. (c) Valida la solución sustituyendo. (d) Escribe una respuesta en una oración.

Solucionario razonado y pauta de la actividad abierta
  • R1. Sí. 4 + 9 = 13.
  • R2. x + 5 = 12. Se usa x para el número.
  • R3. 10. 10 − 3 = 7.
  • C1. No. 3 · 5 + 2 = 17, no es 14.
  • C2. x = 9. 2 · 9 = 18.
  • C3. 3x − 4 = 20. El triple es 3x y se resta 4.
  • A1. 2h + 700 = 3.500; h = 1.400. 3.500 − 700 = 2.800 y 2.800 ÷ 2 = 1.400.
  • A2. 24. n + 5 = 29 da n = 24.
  • A3. 6 semanas. 4.000 + 1.500s = 13.000 da 1.500s = 9.000 y s = 6.
  • Z1. No. 2 · 9 + 3 = 21, no 15.
  • Z2. No; es 2x − 5 = 11. El doble se aplica a x y luego se resta 5.
  • D1. n + (n + 1) = 31; 15 y 16. 15 + 16 = 31.
  • D2. 8 cm. x + x + (x + 2) = 26 da 3x = 24 y x = 8.
  • S1. 8 km. 1.000 + 300k = 3.400 da 300k = 2.400 y k = 8.
  • E1. Sí. 5 · 2 − 1 = 9.
  • E2. x = 8. 20 − 12 = 8.
  • E3. x/2 = 6. La mitad es x dividido entre 2.

Ejemplo de respuesta: (a) Sea e el precio de una entrada: 4e + 1.200 = 9.200. (b) 4e = 8.000, e = 2.000. (c) 4 · 2.000 + 1.200 = 9.200. (d) Cada entrada costó $2.000.

Criterios: define la incógnita; escribe la ecuación correcta; resuelve y valida; responde con unidad.

Evidencias aceptables: ecuación escrita; solución con validación; respuesta en una oración.

Errores que conviene detectar: no definir la letra; no validar sustituyendo.

Retroalimentación constructiva: Pide que lea la ecuación en voz alta con palabras y que compruebe que dice lo mismo que el problema.

Refuerzo. Escribe la ecuación y resuelve: «un número más 11 es igual a 30».

Profundización. Inventa un problema que se resuelva con la ecuación 5x − 3 = 22 y resuélvelo.

Apoyo: Reduce temporalmente el rango o la cantidad, conserva la relación matemática y permite material concreto, tabla, recta o dibujo antes del símbolo; después retorna al desafío original.

Profundización: Cambia una condición de patrones de baldosas, perímetros variables y tablas de entrada y salida, predice el efecto y crea un contraejemplo que obligue a revisar la estrategia inicial.

Tarea breve y flexible

Crea o busca un ejemplo cotidiano seguro del foco y explícalo con dibujo, nota u oralidad. No requiere internet, impresión, compras ni datos familiares.

Banco opcional

Actividades complementarias

  • Recuperación: resolver un caso con menor carga y volver al original.

  • Transferencia: cambiar una condición o representación y revisar la respuesta.
