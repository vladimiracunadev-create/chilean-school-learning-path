Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé qué pasa cuando sumo 0 a un número. Sirve para saber el resultado sin contar cuando no se agrega nada.

Lo que ya debo saber. Sé que sumar es agregar. Sé qué es el número 0: ninguna cantidad.

Explicación

Sumar es agregar objetos. El número 0 significa que no hay nada. Si agregas 0 objetos, no agregas ninguno. Por eso la cantidad queda igual.

Imagina una bandeja con 14 fichas. Agregas 0 fichas: la bandeja sigue con 14. Se escribe 14 + 0 = 14. También puedes empezar con 0 y agregar 14: 0 + 14 = 14. Es lo mismo, porque el total es la cantidad de fichas que hay al final.

Siempre que sumes 0 a un número, el resultado es ese mismo número. No importa si es chico o grande: 6 + 0 = 6, y 58 + 0 = 58. El 0 no cambia la cantidad, y no la hace desaparecer.

Palabras importantes

PalabraQué significa
cero (0)ninguna cantidad
agregarponer más objetos
cantidad iniciallo que hay antes de agregar
cantidad finallo que hay después de agregar
quedar igualno cambiar

Ejemplos resueltos paso a paso

Ejemplo 1. Agregar 0 fichas

Problema: En una bandeja hay 14 fichas. Agregas 0 fichas. ¿Cuántas hay ahora?

  1. Cantidad inicial: 14 fichas.
  2. Agrego 0: no pongo ninguna.
  3. La bandeja no cambió y sigue con 14.
  4. Lo escribo: 14 + 0 = 14.

Respuesta: 14 + 0 = 14

Ejemplo 2. Empezar en cero

Problema: Una caja está vacía. Agregas 9 lápices. ¿Cuántos lápices hay?

  1. Cantidad inicial: 0 lápices (caja vacía).
  2. Agrego 9 lápices.
  3. Ahora hay 9 lápices.
  4. Lo escribo: 0 + 9 = 9.

Respuesta: 0 + 9 = 9

Errores frecuentes y cómo reconocerlos

  • Error: Decir que 52 + 0 = 0. Por qué ocurre: Se piensa que sumar 0 borra el número. Cómo corregirlo: Sumar 0 es no agregar nada. La cantidad queda como estaba: 52 + 0 = 52.
  • Error: Decir que 7 + 0 = 70. Por qué ocurre: Se pone el 0 al lado del 7 como si formara otro número. Cómo corregirlo: Sumar 0 no agrega nada. 7 + 0 = 7.

Para el estudiante

Cuaderno del estudiante

Lo que aprenderé y para qué sirve. Aprenderé qué pasa cuando resto 0 a un número. Sirve para saber cuánto queda cuando no se quita nada.

Lo que ya debo saber. Sé que restar es quitar. Sé que sumar 0 no cambia el número.

Explicación

Restar es quitar objetos. Si quitas 0 objetos, no sacas ninguno. Entonces todos los objetos siguen donde estaban. La cantidad que queda es la misma que había al comienzo.

Piensa en 19 cubos en una bandeja. Retiras 0 cubos: ningún cubo se mueve y quedan 19. Se escribe 19 − 0 = 19. Se lee: diecinueve menos cero es diecinueve.

Siempre que restes 0 a un número, el resultado es ese mismo número. 8 − 0 = 8 y 75 − 0 = 75. No se quita nada, por eso no queda menos. Puedes comprobarlo sumando: 19 + 0 = 19, que vuelve al número del comienzo.

Lo que ya debo saber. Sé que restar 0 deja el mismo número. Sé que no se puede quitar lo que no existe.

Explicación

Hay dos restas con 0 que se parecen pero son distintas. En 8 − 0 empiezas con 8 objetos y quitas ninguno. Quedan 8. Se puede hacer, y el resultado es 8.

En 0 − 8 empiezas sin nada y quieres quitar 8. No tienes objetos para sacar. Con los números que conocemos, esa resta no se puede hacer. En cambio, 0 − 0 sí se puede: no hay nada, no quitas nada, y queda 0.

También es útil recordar esto: si restas a un número el mismo número, el resultado es 0. Por ejemplo, 8 − 8 = 0, porque quitas todo. No confundas 8 − 8 = 0 con 8 − 0 = 8. En una quitas todo y en la otra no quitas nada.

Lo que ya debo saber. Sé que n + 0 = n y n − 0 = n. Sé que 0 − n no se puede con estos números.

Explicación

Ya viste que 14 + 0 = 14 y 19 − 0 = 19. ¿Pasará lo mismo con otros números? Probemos con números chicos y grandes: 6 + 0 = 6, 40 + 0 = 40, 83 − 0 = 83 y 100 − 0 = 100. En todos el resultado es el número del comienzo.

Cuando algo se repite en muchos casos y entendemos por qué, podemos escribir una regla. La regla es: si sumas 0 a un número, o restas 0 a un número, el número no cambia. Se cumple porque 0 significa que no agregas ni quitas nada.

Para explicar bien una regla, muestra ejemplos y di por qué. Un buen ejemplo es un dibujo antes y después. Si el dibujo no cambia, la regla se cumple. No olvides la excepción: 0 − n no se puede hacer cuando n es mayor que 0.

Distribución de 45 minutos

TiempoAcción preservada
5 minActivación breve y lectura de la consigna exacta.
8 minModelado con el insumo concreto y una decisión visible.
12 minPrimer intento guiado y retroalimentación según un criterio.
15 minDesempeño individual con evidencia atribuible.
5 minTicket, clasificación del nivel y decisión posterior.

Decisión posterior: Avanza cuando la representación, el resultado y la explicación coinciden; si no, identifica si el nudo está en el concepto, la traducción o la comprobación y reenseña con otro ejemplo.

Si dispone de 45 minutos: Conserva el ejemplo específico, una práctica guiada, el desempeño individual y el ticket; reduce la cantidad de casos, no la representación ni la explicación.

Consolidación

Tarea breve y flexible

Busca o inventa una situación cotidiana pequeña que use la idea matemática de la clase, represéntala con objetos seguros o dibujo y registra una comprobación. No requiere internet, impresión ni compras.

Banco opcional

Actividades complementarias

  • Recuperación: reduce el rango numérico o la cantidad de condiciones, conserva la misma relación y vuelve luego al caso original.
  • Análisis de error: corrige un caso ficticio basado en esta confusión frecuente: confundir no hacer un cambio con dejar la respuesta en cero.
  • Profundización: cambia un dato o una condición, predice el efecto y comprueba antes de aceptar el resultado.
