# Registros de revisión y pilotaje

Esta carpeta recibe evidencia humana trazable. No contiene registros aprobados todavía.

- Las revisiones usan `review-record.schema.json`.
- Los pilotajes usan `pilot-record.schema.json`.
- El nombre recomendado es `AAAA-MM-DD-nivel-asignatura-oa-tipo.json`.
- Nunca se guardan datos personales, imágenes, diagnósticos ni producciones identificables de estudiantes.

La CI puede validar estructura, pero no puede afirmar que la revisión o el pilotaje ocurrieron.
