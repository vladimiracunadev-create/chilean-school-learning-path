# Contribuir

Las contribuciones deben mejorar claridad, trazabilidad o aplicación. No incluyas material de
terceros sin permiso verificable.

1. Explica el problema y el público afectado.
2. Añade la fuente primaria para afirmaciones jurídicas o normativas.
3. Distingue la regla general del contexto chileno y de otros países.
4. Registra contenido externo en el registro de fuentes.
5. Ejecuta `python scripts/validate_licensing.py` y `python -m unittest discover -s tests -v`.

Al contribuir confirmas que puedes enviar tu aporte. El código se recibe bajo MIT y el contenido
educativo original bajo CC BY-NC-SA 4.0, según [LICENSING.md](LICENSING.md).
