## Qué se debe aprender
> Usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento.

> **Derechos y procedencia:** el código y la redacción del OA anterior proceden de
> Currículum Nacional (MINEDUC) y se reproducen con enlace y fecha de consulta para
> trazabilidad. No se declaran obra del proyecto ni quedan cubiertos por la licencia
> CC BY-NC-SA 4.0 del contenido pedagógico original. Consulta
> [LICENSING.md](../../../LICENSING.md).

**Explicación pedagógica.** Usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento avanza desde diseñar, elaborar, probar y comunicar soluciones tecnológicas de 5° básico mediante decisiones situadas. Cada clase cambia la evidencia y forma de participación, y enfrenta la confusión «en usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento, usar herramientas o datos sin revisar seguridad y privacidad».

**Antes de comenzar.** diseñar, elaborar, probar y comunicar soluciones tecnológicas de 5° básico

**Vocabulario explícito:** necesidad, usuario, criterio, restricción, herramienta, prototipo, prueba, impacto.

### Clase 1 de 5: Definir necesidad, usuario y criterio · Usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento {#cl-07123}
**Estado editorial:** Desarrollada con contenido específico.

**Propósito docente:** Enseñar usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento a través de «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento», con una experiencia disciplinar específica, segura y revisable.

**Meta para estudiantes:** Hoy desarrollaré «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento» y explicaré una decisión con evidencia.

| Momento | Tiempo | Acción docente y experiencia |
|---|---:|---|
| Inicio | 10 min | Presenta un desafío documentado, recursos disponibles y criterios previos para usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento como problema abierto para «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento». Cada estudiante registra qué debe lograrse, para quién y una restricción antes de nombrar soluciones. |
| Modelado | 20 min | Piensa en voz alta como diseñador para definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento: separa necesidad, usuario, decisión, prueba, seguridad y autoría; conserva un intento fallido y contrasta «en usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento, usar herramientas o datos sin revisar seguridad y privacidad». |
| Práctica guiada | 25 min | En parejas desarrollan una variante de «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento», registran acción y resultado y comparan dos soluciones mediante criterios técnicos, ambientales, comunicativos o de seguridad. |
| Desempeño individual | 25 min | Resuelve una versión nueva de «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento» sin copiar el modelo; toma una decisión técnica o digital, produce evidencia y revisa según el criterio acordado. |
| Cierre | 10 min | Para «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento», muestra diseño, archivo, procedimiento o resultado y explica qué decisión cumple el criterio y qué debe mejorar. |

**Materiales y preparación:** un desafío documentado, recursos disponibles y criterios previos para usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento; materiales, herramientas o software disponibles con alternativa desconectada; protección y organización acordes a la tarea.

**Recurso listo para usar:** Desafío de diseño: construir con cartón reutilizado, papel y cinta una solución estable para sostener 9 fichas; límite de base 20 × 20 cm y tres pruebas registradas.

**Consigna exacta:** Para «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento», define usuario y dos criterios, dibuja con medidas, construye o simula, registra tres pruebas y modifica una sola variable.

**Apoyo en el mismo OA:** Ofrece materiales precortados, plantillas de organización, dispositivo compartido, atajos accesibles o alternativa desconectada; no ejecuta la decisión del estudiante.

**Profundización:** Cambia usuario, material, dato, audiencia o restricción y adapta la solución; luego vuelve a probar o revisar.

**Evidencia:** Diseño, objeto, archivo o registro individual de «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento» con propósito, decisión, prueba, seguridad y mejora explicados.

**Criterios de éxito:** resuelve la consigna exacta de «definir necesidad, usuario y criterio · usar procesador de textos para crear, editar, dar formato, incorporar elementos de diseño, revisar y guardar un documento»; usa al menos dos datos, rasgos o evidencias del insumo concreto; explica una decisión y revisa su respuesta ante una condición nueva.

**Decisión posterior:** Avanza cuando decisión, evidencia y explicación coinciden; si no, cambia acceso o ejemplo y vuelve a recoger evidencia sin etiquetar al estudiante.

**Adaptación a 45 minutos:** Conserva situación específica, modelado, práctica guiada, desempeño individual y cierre; reduce cantidad o turnos, no el criterio disciplinar.

**Tarea breve y flexible:** Observa, practica o registra una versión breve y segura con recursos disponibles. No requiere compras, internet, datos personales ni exposición familiar, corporal o emocional.

- Transferencia: cambia contexto, material, audiencia, regla o condición y explica qué debe adaptarse.
