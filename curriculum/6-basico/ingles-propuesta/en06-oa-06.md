### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a leer y entender textos que expresan cantidades y enumeran, con There is, There are, números, how many, more than y fewer than, y los números ordinales. Sirve para entender informes, listas y resultados.

**Lo que ya debo saber.** Sé contar hasta cien en inglés. Conozco palabras como books, chairs y windows.

**Explicación.**

Para decir cuántas cosas hay se usa There is (hay, para uno) y There are (hay, para más de uno). There is one teacher. There are four windows. En negativo: There isn't a... y There aren't any... Para preguntar la cantidad se usa How many...? y la respuesta es un número: twenty-eight (veintiocho), three hundred (trescientos), two hundred and fifty (doscientos cincuenta).

Para comparar cantidades usamos more than (más que) y fewer than (menos que). Con cosas que se cuentan se dice fewer, como en fewer comics. Para enumerar, se usan los números ordinales: first (primero), second (segundo), third (tercero), fourth (cuarto) y fifth (quinto). También se enumera con listas: First,... Second,... Third,...

Al leer un texto con muchos números, subráyalos y escribe qué cuenta cada uno. Después, haz las operaciones necesarias: sumar para saber el total o restar para comparar. Comprueba tus resultados con lo que dice el texto: si dice more, el primer número debe ser mayor. Eso te ayuda a descubrir errores.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| There is / There are | hay (uno) / hay (varios) |
| How many? | ¿cuántos? |
| more than / fewer than | más que / menos que |
| first, second, third | primero, segundo, tercero |
| fourth, fifth | cuarto, quinto |
| hundred | cien (un centenar) |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Leer una cantidad*

Problema: Lee: «On the table there are three pens, one ruler and two erasers.» (pens = lápices de pasta, ruler = regla, erasers = gomas). ¿Cuántos objetos hay en total?

1. Anoto cada cantidad: 3, 1 y 2.
2. Sumo: 3 + 1 + 2.
3. El total es 6.

Respuesta: 6 objetos

*Ejemplo 2. Ordinales*

Problema: Lee: «Lucas finished second and Ana finished fifth.» (finished = terminó). ¿Quién llegó antes a la meta?

1. Second es el segundo lugar y fifth el quinto.
2. Un lugar con número menor llega antes.
3. Lucas llegó antes.

Respuesta: Lucas

**Errores frecuentes y cómo reconocerlos**

- **Error:** Usar There is con varios objetos: «There is four windows». **Por qué ocurre:** No se concuerda el verbo con la cantidad. **Cómo corregirlo:** Con más de uno, usa There are.
- **Error:** Decir fewer comics como «más historietas». **Por qué ocurre:** Se confunde fewer con more. **Cómo corregirlo:** Fewer es menos y more es más.

**Solucionario razonado**

- **R1.** b) 4. Dice four windows.
- **R2.** 16. Dice sixteen boys.
- **R3.** No. Dice there aren't any computers.
- **C1.** 2. Hay treinta sillas y veintiocho estudiantes. Cálculo: 30 − 28 = 2.
- **C2.** 29. Son 28 estudiantes y 1 profesor. Cálculo: 28 + 1 = 29.
- **C3.** There is. El sujeto one teacher es singular.
- **A1.** 550. Se suman los libros de ambos temas. Cálculo: 300 + 250 = 550.
- **A2.** 50. Se resta el número menor del mayor. Cálculo: 300 − 250 = 50.
- **A3.** 730. Se suman las tres cantidades. Cálculo: 300 + 250 + 180 = 730.
- **Z1.** b) historietas. 180 es el número menor.
- **Z2.** Zoe llegó tercera y Pablo cuarto. Third es Zoe y Fourth es Pablo.
- **D1.** No. Hay 12 niñas y 16 niños; hay más niños.
- **D2.** 4. Se comparan 16 niños con 12 niñas. Cálculo: 16 − 12 = 4.
- **S1.** 12. Dice twelve cupcakes.
- **E1.** Con más de un objeto. Se usa con plurales.
- **E2.** Menos que. Sirve para comparar cantidades.
- **E3.** fifth. Es el ordinal de cinco.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a leer textos que describen acciones y cómo se realizan, con verbos en presente y adverbios como slowly, carefully y well. Sirve para entender instrucciones, relatos y descripciones.

**Lo que ya debo saber.** Sé que run, write y speak son acciones. Conozco palabras como fast, slow y quiet.

**Explicación.**

Un adverbio de modo (adverb of manner) dice cómo se hace una acción. Muchos se forman agregando -ly a un adjetivo: slow → slowly (lentamente), careful → carefully (con cuidado), quiet → quietly (en voz baja), loud → loudly (fuerte), neat → neatly (ordenadamente). El adverbio va después del verbo: She walks slowly.

Algunos adverbios son especiales. Good (bueno) se convierte en well (bien): He plays well. Fast se queda igual: She runs fast. Hard también se queda igual: They work hard (trabajan duro). Para acciones que ocurren ahora se usa el presente continuo: is/are + verbo con -ing, como Tomás is running slowly.

Para comprender un texto con muchas acciones, busca quién hace cada acción (el sujeto) y cómo la hace (el adverbio). Después, comprueba si la manera concuerda con la razón: Tomás corre slowly because su zapato está desatado. La palabra because explica el porqué de la manera de hacer la acción.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| adverb of manner | adverbio de modo: cómo se hace algo |
| slowly / quickly | lentamente / rápido |
| carefully | con cuidado |
| quietly / loudly | en voz baja / fuerte |
| well | bien |
| -ing | terminación de acción en curso |

**Ejemplos resueltos paso a paso**

Respuesta: En silencio

Respuesta: carefully

**Errores frecuentes y cómo reconocerlos**

- **Error:** Decir «She plays good» en vez de «She plays well». **Por qué ocurre:** Se usa el adjetivo en lugar del adverbio. **Cómo corregirlo:** Con verbos, good se cambia por well.
- **Error:** Escribir «He walks slow» en vez de «He walks slowly». **Por qué ocurre:** Se usa el adjetivo en lugar del adverbio de modo. **Cómo corregirlo:** Para decir cómo se camina, agrega -ly: slowly.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a leer textos que identifican y describen objetos, deportes y pasatiempos, y que expresan gustos, opiniones, necesidades y comparaciones. Sirve para entender perfiles, anuncios y descripciones.

**Lo que ya debo saber.** Sé decir I like y I don't like. Conozco palabras como big, small, fast y slow.

**Explicación.**

Para describir un objeto se usan adjetivos: blue, big, light (liviano), heavy (pesado). Para hablar de pasatiempos y deportes, se usan sustantivos y verbos con -ing: painting, playing chess, swimming. Para expresar gustos: I like..., I love..., My favourite ... is... (mi ... favorito es...). Para opinar: I think... because... Para necesidades: I need ___ (necesito). Para intenciones: I'd like to ___ (me gustaría ___).

Para comparar dos cosas se usa el comparativo. Con adjetivos cortos se agrega -er y than: faster than (más rápido que), bigger than (más grande que), heavier than (más pesado que). Con adjetivos largos se usa more y than: more interesting than (más interesante que). El adjetivo good cambia a better (mejor) y bad a worse (peor).

Cuando leas un perfil o un anuncio, busca tres cosas: lo que la persona tiene o hace, lo que le gusta y lo que necesita o quiere. Subraya las comparaciones y piensa cuál es la cosa que se coloca primero. En «chess is more interesting than football», el ajedrez es lo que se describe como más interesante.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a leer textos que expresan intenciones, planes futuros y predicciones, con going to y will. Sirve para entender planes de un paseo, pronósticos y textos sobre el futuro.

**Lo que ya debo saber.** Sé usar tomorrow y next week. Conozco verbos como visit, bring y wear.

**Explicación.**

Para hablar de un plan o una intención se usa be going to + verbo: We are going to visit the beach (vamos a visitar la playa). En negativo: We are not going to swim (no vamos a nadar). Las palabras de tiempo ayudan: tomorrow (mañana), next Saturday (el próximo sábado), next year (el próximo año), in the future (en el futuro).

Para hacer una predicción o una decisión espontánea se usa will + verbo: It will be sunny (estará soleado). En negativo: will not o won't. Se usa con palabras como think (creo), maybe (quizás), probably (probablemente). Diferencia clave: going to expresa un plan que ya está decidido; will expresa una predicción o lo que pensamos que ocurrirá.

Al leer un texto sobre el futuro, haz dos listas: planes (going to) y predicciones (will). Pregúntate quién hace el plan, cuándo y qué razón da. Si dice because, la razón explica el plan. Por ejemplo, They are not going to swim because the water will be cold: el plan se explica con una predicción.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| going to + verbo | voy a / vamos a (plan) |
| will + verbo | predicción: ocurrirá |
| tomorrow / next year | mañana / el próximo año |
| maybe | quizás |
| won't | no ocurrirá |
| plan / prediction | plan / predicción |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Reconocer un plan*

Problema: Lee: «Tomorrow, I am going to study for the Math test.» (study = estudiar, test = prueba). ¿Qué plan expresa?

1. Veo am going to study.
2. Es un plan para mañana.
3. Estudiar para la prueba de Matemática.

Respuesta: Estudiar para la prueba de Matemática mañana

*Ejemplo 2. Reconocer una predicción*

Problema: Lee: «I think it will rain tonight.» (rain = llover, tonight = esta noche). ¿Es un plan o una predicción?

1. Veo will rain.
2. Dice I think, que es una opinión sobre el futuro.
3. Es una predicción.

Respuesta: Una predicción

**Errores frecuentes y cómo reconocerlos**

- **Error:** Usar will para todo plan. **Por qué ocurre:** No se distingue plan de predicción. **Cómo corregirlo:** Un plan decidido usa going to; una predicción usa will.
- **Error:** Olvidar to en going to. **Por qué ocurre:** Se escribe going visit. **Cómo corregirlo:** Es going to + verbo.

**Criterios para evaluarla:** anota dos planes; anota dos predicciones; indica la consecuencia.

**Evidencias aceptables:** hoja con respuestas; nota del adulto.

**Errores que conviene detectar:** confundir plan con predicción; olvidar la consecuencia.

**Retroalimentación constructiva:** Reconoce la clasificación correcta y muestra cómo reconocer going to y will en cada oración.

## Evaluación integradora y realidad escolar
Evalúa contenido, respuesta al verbo, evidencia o razonamiento y comunicación/revisión. Registra evidencia individual. La propuesta funciona con pizarra, cuaderno y materiales disponibles; la conectividad no es requisito. En cursos numerosos usa respuestas simultáneas, estaciones y grupos temporales. Considera diversidad lingüística, cultural, sensorial y motriz.
