### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé qué pasa cuando sumo 0 a un número. Sirve para saber el resultado sin contar cuando no se agrega nada.

**Lo que ya debo saber.** Sé que sumar es agregar. Sé qué es el número 0: ninguna cantidad.

**Explicación.**

Sumar es agregar objetos. El número 0 significa que no hay nada. Si agregas 0 objetos, no agregas ninguno. Por eso la cantidad queda igual.

Imagina una bandeja con 14 fichas. Agregas 0 fichas: la bandeja sigue con 14. Se escribe 14 + 0 = 14. También puedes empezar con 0 y agregar 14: 0 + 14 = 14. Es lo mismo, porque el total es la cantidad de fichas que hay al final.

Siempre que sumes 0 a un número, el resultado es ese mismo número. No importa si es chico o grande: 6 + 0 = 6, y 58 + 0 = 58. El 0 no cambia la cantidad, y no la hace desaparecer.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| cero (0) | ninguna cantidad |
| agregar | poner más objetos |
| cantidad inicial | lo que hay antes de agregar |
| cantidad final | lo que hay después de agregar |
| quedar igual | no cambiar |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Agregar 0 fichas*

Problema: En una bandeja hay 14 fichas. Agregas 0 fichas. ¿Cuántas hay ahora?

1. Cantidad inicial: 14 fichas.
2. Agrego 0: no pongo ninguna.
3. La bandeja no cambió y sigue con 14.
4. Lo escribo: 14 + 0 = 14.

Respuesta: 14 + 0 = 14

*Ejemplo 2. Empezar en cero*

Problema: Una caja está vacía. Agregas 9 lápices. ¿Cuántos lápices hay?

1. Cantidad inicial: 0 lápices (caja vacía).
2. Agrego 9 lápices.
3. Ahora hay 9 lápices.
4. Lo escribo: 0 + 9 = 9.

Respuesta: 0 + 9 = 9

**Errores frecuentes y cómo reconocerlos**

- **Error:** Decir que 52 + 0 = 0. **Por qué ocurre:** Se piensa que sumar 0 borra el número. **Cómo corregirlo:** Sumar 0 es no agregar nada. La cantidad queda como estaba: 52 + 0 = 52.
- **Error:** Decir que 7 + 0 = 70. **Por qué ocurre:** Se pone el 0 al lado del 7 como si formara otro número. **Cómo corregirlo:** Sumar 0 no agrega nada. 7 + 0 = 7.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé qué pasa cuando resto 0 a un número. Sirve para saber cuánto queda cuando no se quita nada.

**Lo que ya debo saber.** Sé que restar es quitar. Sé que sumar 0 no cambia el número.

**Explicación.**

Restar es quitar objetos. Si quitas 0 objetos, no sacas ninguno. Entonces todos los objetos siguen donde estaban. La cantidad que queda es la misma que había al comienzo.

Piensa en 19 cubos en una bandeja. Retiras 0 cubos: ningún cubo se mueve y quedan 19. Se escribe 19 − 0 = 19. Se lee: diecinueve menos cero es diecinueve.

Siempre que restes 0 a un número, el resultado es ese mismo número. 8 − 0 = 8 y 75 − 0 = 75. No se quita nada, por eso no queda menos. Puedes comprobarlo sumando: 19 + 0 = 19, que vuelve al número del comienzo.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| restar | quitar una cantidad |
| cero (0) | ninguna cantidad |
| quedan | los objetos que siguen después de quitar |
| cantidad inicial | lo que hay antes de quitar |
| comprobar | revisar el resultado con otra operación |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Quitar 0 cubos*

Problema: En una bandeja hay 19 cubos. Quitas 0 cubos. ¿Cuántos quedan?

1. Cantidad inicial: 19 cubos.
2. Quito 0: no saco ninguno.
3. Quedan los 19 cubos.
4. Compruebo: 19 + 0 = 19.

Respuesta: 19 − 0 = 19

*Ejemplo 2. Restar 0 a un número grande*

Problema: Una caja tiene 75 hojas. Sacas 0 hojas. ¿Cuántas hojas quedan?

1. Cantidad inicial: 75 hojas.
2. No saco ninguna hoja.
3. Quedan 75 hojas.
4. Compruebo: 75 + 0 = 75.

Respuesta: 75 − 0 = 75

**Errores frecuentes y cómo reconocerlos**

- **Error:** Decir que 19 − 0 = 0. **Por qué ocurre:** Se cree que restar 0 deja cero. **Cómo corregirlo:** Restar 0 es no quitar nada. Quedan los 19 objetos.
- **Error:** Decir que 30 − 0 = 3. **Por qué ocurre:** Se saca el 0 del número 30 como si fuera parte de la resta. **Cómo corregirlo:** El número es 30 y no se quita nada. 30 − 0 = 30.

**Lo que aprenderé y para qué sirve.** Aprenderé a decir una regla que sirve para cualquier número al sumar o restar 0. Sirve para reconocer que algo es siempre cierto, y no solo en un caso.

**Lo que ya debo saber.** Sé que n + 0 = n y n − 0 = n. Sé que 0 − n no se puede con estos números.

**Explicación.**

Ya viste que 14 + 0 = 14 y 19 − 0 = 19. ¿Pasará lo mismo con otros números? Probemos con números chicos y grandes: 6 + 0 = 6, 40 + 0 = 40, 83 − 0 = 83 y 100 − 0 = 100. En todos el resultado es el número del comienzo.

Cuando algo se repite en muchos casos y entendemos por qué, podemos escribir una regla. La regla es: si sumas 0 a un número, o restas 0 a un número, el número no cambia. Se cumple porque 0 significa que no agregas ni quitas nada.

Para explicar bien una regla, muestra ejemplos y di por qué. Un buen ejemplo es un dibujo antes y después. Si el dibujo no cambia, la regla se cumple. No olvides la excepción: 0 − n no se puede hacer cuando n es mayor que 0.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| regla | algo que siempre se cumple |
| regularidad | lo que se repite en varios casos |
| ejemplo | un caso que muestra la regla |
| explicar | decir por qué algo es cierto |
| excepción | caso donde la regla no sirve |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Mirar varios casos*

Problema: Compara 6 + 0, 40 + 0, 83 − 0 y 100 − 0. ¿Qué regla ves?

1. 6 + 0 = 6: es el mismo número.
2. 40 + 0 = 40: es el mismo número.
3. 83 − 0 = 83 y 100 − 0 = 100: también es el mismo.
4. Regla: sumar o restar 0 no cambia el número.

Respuesta: Sumar o restar 0 deja igual el número

*Ejemplo 2. Usar la regla*

Problema: Sin hacer cuentas, ¿cuánto es 97 + 0 y cuánto es 97 − 0?

1. Aplico la regla: sumar o restar 0 no cambia el número.
2. 97 + 0 = 97.
3. 97 − 0 = 97.
4. No necesito contar porque 0 no agrega ni quita.

Respuesta: 97 y 97

**Errores frecuentes y cómo reconocerlos**

- **Error:** Decir que la regla solo sirve para números chicos. **Por qué ocurre:** Se prueba solo con unos pocos números. **Cómo corregirlo:** La regla vale para cualquier número, porque el 0 siempre significa «nada».
- **Error:** Decir que 0 − 6 = 6 por la misma regla. **Por qué ocurre:** Se aplica la regla de n − 0 a una resta distinta. **Cómo corregirlo:** La regla es para restar 0. Con 0 − 6 no hay qué quitar.

*Situaciones auténticas*

- **S1.** Un granjero tiene 100 huevos. Vende 0 y le regalan 0. ¿Cuántos huevos tiene al final?

*Autoevaluación*

- **E1.** Calcula 75 + 0.
- **E2.** Calcula 75 − 0.
- **E3.** ¿Se puede hacer 0 − 5?

**Actividad abierta.** Resuelve estas cuatro operaciones y comprueba cada una con un dibujo de barras y cubos antes y después: 29 + 0, 34 + 0, 38 − 0 y 100 − 0. Escribe una regla con tus palabras y una excepción.

**Solucionario razonado**

- **R1.** 6. Sumar 0 deja el mismo número. Cálculo: 6 + 0 = 6.
- **R2.** 40. Sumar 0 deja el mismo número. Cálculo: 40 + 0 = 40.
- **R3.** 83. Restar 0 deja el mismo número. Cálculo: 83 − 0 = 83.
- **C1.** 100. No se quita nada.
- **C2.** Verdadero. El 0 no agrega nada, sin importar el número.
- **C3.** no cambia. El 0 significa ninguna cantidad.
- **A1.** 100. Se aplica la regla. Cálculo: 100 − 0 = 100.
- **A2.** 97. Se aplica la regla. Cálculo: 97 + 0 = 97.
- **A3.** 56 y 0. El número que sumas o restas es 0.
- **Z1.** Que también sirve con 40, 83 o 100; el 0 no agrega ni quita nada en ningún número. La razón no depende del tamaño del número.
- **Z2.** 0 − 12. En 0 − 12 el 0 es el número del que se parte, no el que se resta.
- **D1.** 70 + 0 = 70 y 70 − 0 = 70 (también sirve 0 + 70 = 70). Sumar o restar 0 a 70 deja 70.
- **D2.** 45. Cada paso deja el número igual. Cálculo: 45 + 0 − 0 = 45.
- **S1.** 100. No cambia la cantidad en ningún paso. Cálculo: 100 − 0 + 0 = 100.
- **E1.** 75. Sumar 0 deja igual. Cálculo: 75 + 0 = 75.
- **E2.** 75. Restar 0 deja igual. Cálculo: 75 − 0 = 75.
- **E3.** No. No hay nada para quitar.

**Actividad abierta · ejemplo de respuesta.** 29 + 0 = 29: ▮ ▮ | ● ● ● ● ● ● ● ● ●. 34 + 0 = 34: ▮ ▮ ▮ | ● ● ● ●. 38 − 0 = 38: ▮ ▮ ▮ | ● ● ● ● ● ● ● ●. 100 − 0 = 100: diez barras de 10. Regla: si sumo o resto 0, el número queda igual. Excepción: 0 − 5 no se puede hacer.

**Criterios para evaluarla:** resuelve las cuatro operaciones; dibuja antes y después; escribe la regla y la excepción.

**Evidencias aceptables:** cuatro operaciones; dibujos; regla escrita.

**Errores que conviene detectar:** decir que la regla solo sirve con números chicos; aplicar la regla a 0 − n.

**Retroalimentación constructiva:** Pide que lea su regla en voz alta con un ejemplo distinto al de su cuaderno; reconoce la excepción.

**Refuerzo.** Usa los números 23, 56 y 91. Escribe para cada uno el número más 0 y el número menos 0.

**Profundización.** Explica por qué sumar 0 no cambia un número, y por qué una resta como 0 − 5 no sigue la regla.


**Apoyo en el mismo OA:** Representa cero con una acción visible —no agregar o no retirar— antes de escribir la expresión.

**Profundización:** Explica por qué sumar o restar cero mantiene cualquier número y distingue 0−n de n−0.

**Evidencia:** Completa y justifica: __ + 0 = 68 y 91 − __ = 91. acompañada de una representación y una comprobación atribuibles al estudiante.

**Criterios de éxito:** representa la acción del cero; mantiene la cantidad al sumar o restar cero; distingue el orden en una sustracción.

**Decisión posterior:** Avanza cuando la representación, el resultado y la explicación coinciden; si no, identifica si el nudo está en el concepto, la traducción o la comprobación y reenseña con otro ejemplo.

**Adaptación a 45 minutos:** Conserva el ejemplo específico, una práctica guiada, el desempeño individual y el ticket; reduce la cantidad de casos, no la representación ni la explicación.

**Tarea breve y flexible:** Busca o inventa una situación cotidiana pequeña que use la idea matemática de la clase, represéntala con objetos seguros o dibujo y registra una comprobación. No requiere internet, impresión ni compras.

**Actividades complementarias (opcionales):**
- Recuperación: reduce el rango numérico o la cantidad de condiciones, conserva la misma relación y vuelve luego al caso original.
- Análisis de error: corrige un caso ficticio basado en esta confusión frecuente: confundir no hacer un cambio con dejar la respuesta en cero.
- Profundización: cambia un dato o una condición, predice el efecto y comprueba antes de aceptar el resultado.

**Control de dificultades en el aula**

| Dificultad observable | Acción inmediata | Cómo comprobar si funcionó |
|---|---|---|
| Inicia un cálculo sin representar la situación | Pide identificar datos, relación y pregunta; exige una representación breve antes de operar. | La operación elegida coincide con la relación representada. |
| Confundir no hacer un cambio con dejar la respuesta en cero | Representa cero con una acción visible —no agregar o no retirar— antes de escribir la expresión. | Resuelve un caso nuevo sin repetir la confusión y explica la diferencia. |
| Entrega un resultado sin comprobar | Solicita estimación, operación inversa, segunda representación o sustitución según el OA. | La comprobación permite confirmar o corregir el resultado de manera independiente. |

**Coordinación de roles profesionales:** El docente conduce el razonamiento matemático y registra la estrategia; educación diferencial acuerda acceso a representaciones, manipulación, campo visual o respuesta oral sin entregar el procedimiento ni reducir el OA.

**Integración de habilidad y actitud:**
- **Habilidad · `de Habilidad MA02 OAH b`:** Se observa al comprobar un enunciado con material concreto o gráfico. La evidencia se recoge mientras el estudiante trabaja la meta «formularé una regla sobre sumar y restar cero».
- **Actitud · `de Actitud MA02 OAA F`:** Se promueve expresión y escucha respetuosa de ideas: se reconoce la representación, explicación y revisión, no la rapidez.

## Evaluación integradora y realidad escolar
Evalúa contenido, respuesta al verbo, evidencia o razonamiento y comunicación/revisión. Registra evidencia individual. La propuesta funciona con pizarra, cuaderno y materiales disponibles; la conectividad no es requisito. En cursos numerosos usa respuestas simultáneas, estaciones y grupos temporales. Considera diversidad lingüística, cultural, sensorial y motriz.
