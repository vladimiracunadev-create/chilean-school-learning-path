### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a precisar qué es una potencia de exponente entero (positivo, cero o negativo), qué valores de x admite y cómo se comporta según su signo. Sirve para construir modelos de crecimiento y decrecimiento con f(x) = xⁿ.

**Lo que ya debo saber.** Sé calcular potencias de exponente natural. Sé que no se puede dividir por cero.

**Explicación.**

Una función potencia de exponente entero tiene la forma f(x) = xⁿ, con n un número entero. Si n es positivo, xⁿ es el producto de x por sí mismo n veces. Si n = 0, x⁰ = 1 para todo x distinto de 0. Si el exponente es negativo, −m con m positivo, x⁻ᵐ = 1 ÷ xᵐ, que solo existe para x distinto de 0. Al dividir potencias de igual base se restan los exponentes: xᵃ ÷ xᵇ = xᵃ⁻ᵇ.

El exponente negativo no hace que el resultado sea negativo: es la idea de dividir. Por ejemplo, 2⁻³ = 1/2³ = 1/8, que es positivo. El signo del resultado depende de la base y de si el exponente es par o impar: (−2)³ = −8, (−2)⁴ = 16 y (−2)⁻³ = −1/8.

La paridad de n da simetrías. Si n es par, f(−x) = f(x) y la gráfica es simétrica respecto del eje vertical. Si n es impar, f(−x) = −f(x) y la gráfica es simétrica respecto del origen. Antes de usar una función potencia como modelo, hay que decir su dominio y qué representa x.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| exponente entero | número entero (positivo, cero o negativo) que indica la potencia |
| base | número x que se multiplica por sí mismo |
| dominio | valores de x para los que la función está definida |
| par | número entero divisible por 2 |
| simetría | forma igual a ambos lados de un eje o de un punto |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Evaluar y dominio*

Problema: Para f(x) = x⁻², calcula f(2), f(−2) y f(0).

1. f(2) = 1/2² = 1/4.
2. f(−2) = 1/(−2)² = 1/4, porque el exponente es par.
3. f(0) = 1/0² no existe: 0 no está en el dominio.

Respuesta: f(2) = 1/4; f(−2) = 1/4; f(0) no existe

*Ejemplo 2. Exponente impar*

Problema: Para g(x) = x³, calcula g(−2) y g(2) y describe la simetría.

1. g(2) = 8.
2. g(−2) = (−2)³ = −8.
3. Como g(−x) = −g(x), la gráfica es simétrica respecto del origen.

Respuesta: g(2) = 8; g(−2) = −8; simetría respecto del origen

**Errores frecuentes y cómo reconocerlos**

- **Error:** Decir que 3⁻² = −9 porque «el exponente es negativo». **Por qué ocurre:** El exponente negativo indica dividir, no cambiar el signo. **Cómo corregirlo:** 3⁻² = 1/3² = 1/9.
- **Error:** Calcular 2⁻³ = −6. **Por qué ocurre:** Se multiplicó la base por el exponente. **Cómo corregirlo:** 2⁻³ = 1/(2 · 2 · 2) = 1/8.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a representar una función potencia con una tabla y con una gráfica, y a describir si crece o decrece. Sirve para ver el mismo modelo de dos maneras y detectar errores en cualquiera de ellas.

**Lo que ya debo saber.** Sé evaluar xⁿ con exponentes enteros. Sé leer una tabla de valores y una gráfica.

**Explicación.**

Una tabla de valores y una gráfica son dos representaciones de la misma función. En la tabla, ordenas valores de x y calculas f(x). En la gráfica, ubicas esos pares como puntos y los unes con una curva solo si el dominio lo permite. Si la tabla y la gráfica no coinciden, hay un error en una de las dos.

Para x positivo, f(x) = xⁿ con n positivo crece cuando x crece, y lo hace más rápido cuanto mayor es n. Con exponente negativo, como f(x) = x⁻ᵐ con m positivo, la función decrece cuando x crece: se acerca a 0 sin llegar a 0, y crece sin tope cuando x se acerca a 0 por la derecha. Por ejemplo, x⁻² pasa de 1 a 1/4, 1/9 y 1/16.

Un efecto útil: si x se duplica, xⁿ se multiplica por 2ⁿ. Para n = 2 se multiplica por 4; para n = −2 se multiplica por 1/4. Una potencia no es lo mismo que una exponencial: en x² la variable es la base y en 2ˣ la variable es el exponente. Sus valores se pueden cruzar, pero crecen de forma distinta.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| tabla de valores | lista de pares x y f(x) |
| gráfica | dibujo de los puntos (x, f(x)) en el plano |
| creciente | que aumenta cuando x aumenta |
| decreciente | que disminuye cuando x aumenta |
| proporcionalidad inversa | relación en que si una cantidad se multiplica por k, la otra se divide por k |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Tabla y comportamiento*

Problema: Para f(x) = x⁻¹, completa una tabla con x = 1/2, 1, 2, 4 y describe el comportamiento para x positivo.

1. f(1/2) = 2, f(1) = 1, f(2) = 1/2 y f(4) = 1/4.
2. Los valores bajan a medida que x sube, pero siempre son positivos.

Respuesta: Es decreciente para x > 0 y se acerca a 0

*Ejemplo 2. Potencia y exponencial*

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a construir un modelo periódico y = D + A · sen(bx) o y = D + A · cos(bx) a partir de un máximo, un mínimo y un período. Sirve para describir fenómenos que se repiten, como mareas, temperaturas o ruedas que giran.

**Lo que ya debo saber.** Conozco la circunferencia de radio 1 y los ángulos en grados. Sé resolver ecuaciones de primer grado.

**Explicación.**

Las funciones seno y coseno se definen con la circunferencia de radio 1: para un ángulo x, el punto de la circunferencia es (cos x, sen x). Valores útiles: sen 0° = 0, sen 30° = 1/2, sen 90° = 1, sen 180° = 0, sen 270° = −1, cos 0° = 1, cos 90° = 0 y cos 180° = −1. Ambas funciones se repiten cada 360° (que equivalen a 2π radianes) y sus valores están entre −1 y 1.

Un modelo periódico general es y = D + A · sen(b · t). La amplitud A es la mitad de la distancia entre el máximo y el mínimo: A = (máx − mín) ÷ 2. El nivel medio D es el centro: D = (máx + mín) ÷ 2. Si un ciclo dura P unidades de tiempo, b = 360° ÷ P. Con coseno el modelo es igual, pero parte de su valor máximo en t = 0.

Para construir el modelo: lee el máximo, el mínimo y el período, calcula A, D y b, y comprueba con un valor conocido. Un modelo periódico solo sirve mientras el fenómeno se repita de forma regular; fuera de ese rango, o si cambian las condiciones, hay que revisarlo.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| periódica | que repite sus valores cada cierto intervalo |
| período | duración de un ciclo completo |
| amplitud | mitad de la distancia entre el máximo y el mínimo |
| nivel medio | valor central de la oscilación |
| circunferencia de radio 1 | circunferencia con la que se definen seno y coseno |

**Lo que ya debo saber.** Conozco la circunferencia de radio 1 y las funciones seno y coseno. Sé usar el teorema de Pitágoras.

**Explicación.**

Un punto de la circunferencia de radio 1 tiene coordenadas (cos x, sen x). Como la distancia al centro es 1, el teorema de Pitágoras da la identidad fundamental: sen²x + cos²x = 1, válida para todo ángulo x. Con ella, si conoces uno de los valores y el cuadrante, puedes calcular el otro.

La simetría de la circunferencia da más relaciones: sen(−x) = −sen x, cos(−x) = cos x, sen(180° − x) = sen x, cos(180° − x) = −cos x, sen(180° + x) = −sen x y sen(x + 360°) = sen x. Valores de referencia: sen 30° = 1/2 y cos 60° = 1/2. Para ángulos grandes, resta vueltas de 360°.

Cuando uses una relación, justifícala con el dibujo: ubica el ángulo, marca el punto simétrico y compara coordenadas. Un solo ejemplo numérico no demuestra una identidad; la prueba usa la circunferencia o Pitágoras. Si dos valores dados no cumplen sen²x + cos²x = 1, no pueden ser del mismo ángulo.

| Palabra | Qué significa |
|---|---|
| identidad | igualdad que se cumple para todos los valores permitidos |
| cuadrante | cada una de las cuatro regiones del plano |
| simetría | reflejo de un punto respecto de un eje o del origen |
| ángulo agudo | ángulo menor que 90° |
| vuelta completa | giro de 360° |

**Lo que ya debo saber.** Sé construir modelos con potencias y con seno o coseno. Sé evaluar una fuente de información.

**Explicación.**

Para comprobar un modelo, calcula lo que predice para varios valores y compara con los datos. El error absoluto es |valor real − valor predicho|. El error relativo es el error absoluto dividido por el valor real o por el predicho, en porcentaje. Un buen modelo tiene errores pequeños en todos los datos y no solo en algunos.

Para elegir entre modelos, mira primero la forma de los datos. Si los datos se repiten con regularidad, piensa en un modelo periódico con seno o coseno. Si disminuyen o aumentan sin repetirse, y dependen de una distancia o de una cantidad, piensa en una potencia. Compara los errores totales y revisa si el modelo tiene sentido fuera de los datos.

Cuando uses información de internet, verifica quién publica los datos, cuándo y cómo se midieron, y contrasta con una segunda fuente independiente. Un modelo con buen ajuste en tres datos puede fallar con otros. Comunica siempre el modelo, el dominio donde vale, los errores observados y los límites.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| ajuste | qué tan cerca están las predicciones de los datos |
| error absoluto | diferencia positiva entre el valor real y el predicho |
| error relativo | error absoluto como porcentaje de un valor |
| modelo | función que describe una situación |
| contrastar | comparar con otra fuente o con datos nuevos |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Elegir una potencia*

2. Predicciones: 12 · 1⁻² = 12, 12 · 2⁻² = 3 y 12 · 4⁻² = 0,75, igual a los datos.

Respuesta: f(x) = 12 · x⁻², con error 0

- **D1.** y = 5 · x². k = 5 y 5 · 4 = 20, 5 · 16 = 80.
- **D2.** D = 15 y A = 5. D = (20 + 10) ÷ 2 y A = (20 − 10) ÷ 2.
- **S1.** 5 %. 0,2 ÷ 4 = 0,05.
- **E1.** Sus predicciones con los datos. Se calcula el error de cada dato.
- **E2.** No. Un dato no muestra el patrón.
- **E3.** Quién publica, cuándo y cómo midió. Permite saber si el dato es confiable.

**Actividad abierta · ejemplo de respuesta.** Predicciones: 100, 25, 6,25 y 4. Errores absolutos: 2, 1, 0,25 y 0,2. El modelo es razonable (errores pequeños, mayores en distancias cortas). Fuente: manual de la lámpara o un texto de física con método. Límites: vale para una fuente puntual sin obstáculos y para d > 0.

**Criterios para evaluarla:** calcula predicciones y errores; decide con un criterio explícito; plantea una fuente y dos límites.

**Evidencias aceptables:** tabla con valores reales y predichos; conclusión escrita.

**Errores que conviene detectar:** mirar solo un dato; no indicar el dominio.

**Retroalimentación constructiva:** Si el estudiante afirma que el modelo es perfecto, pide que muestre el error del dato con peor ajuste.

**Refuerzo.** Calcula las predicciones de y = 8 · x⁻¹ para x = 1, 2 y 4 y compáralas con los datos 8; 4,2 y 2.

**Profundización.** Explica por qué un modelo periódico y uno de potencia pueden coincidir en tres datos y aun así ser muy distintos fuera de ellos.


**Apoyo en el mismo OA:** Reduce cantidad de datos, ofrece una representación equivalente y una lista de condiciones; conserva la decisión matemática y no completa el procedimiento.

**Profundización:** Cambia un parámetro, restricción o representación, formula una conjetura y determina si el argumento todavía se sostiene. Realiza la transferencia con menor andamiaje y justifica qué apoyo ya no resulta necesario.

**Evidencia:** Resolución matemática individual de «comprobar y comparar: modelos de crecimiento, decrecimiento y periodicidad» con representación, estrategia, justificación, interpretación y comprobación.

**Criterios de éxito:** desarrolla «comprobar y comparar: modelos de crecimiento, decrecimiento y periodicidad» en el caso propuesto; usa una decisión y evidencia propias de la disciplina; explica el alcance, revisa un error o reconoce una limitación.

**Decisión posterior:** Avanza cuando decisión, evidencia y explicación coinciden; si no, localiza la barrera, modela otro caso y recoge una nueva evidencia sin etiquetar a la persona.

**Adaptación a 45 minutos:** Conserva el caso específico, modelado breve, práctica guiada, evidencia individual y ticket; reduce cantidad o turnos, no la demanda del OA.

**Tarea breve y flexible:** Observa, representa o explica un caso seguro con recursos disponibles. No requiere compras, internet ni revelar datos personales, familiares, corporales o políticos.

**Actividades complementarias (opcionales):**
- Recuperación: reduce variables o elementos y vuelve después al desafío completo.
- Análisis de error: revisa un caso ficticio que muestra esta confusión: aceptar un resultado sin interpretarlo ni verificarlo.
- Transferencia: cambia contexto, fuente, audiencia, escala o restricción y revisa la decisión.

**Control de dificultades en el aula**

| Dificultad observable | Acción inmediata | Cómo comprobar si funcionó |
|---|---|---|
| Responde antes de examinar el caso o la evidencia | Pide localizar primero el dato, rasgo, fuente, criterio o condición que utilizará. | La nueva respuesta cita una evidencia pertinente. |
| Aceptar un resultado sin interpretarlo ni verificarlo | Reduce cantidad de datos, ofrece una representación equivalente y una lista de condiciones; conserva la decisión matemática y no completa el procedimiento. | Resuelve un caso nuevo sin repetir la confusión y explica la diferencia. |
| Completa la actividad, pero no justifica su decisión | Solicita comparar con una alternativa y nombrar el criterio decisivo. | La explicación permite reconstruir y revisar la decisión. |

**Coordinación de roles profesionales:** El docente mantiene lenguaje y demanda matemática; los apoyos de acceso no sustituyen representación, razonamiento ni comprobación individual.

## Evaluación integradora y realidad escolar
Evalúa contenido, respuesta al verbo, evidencia o razonamiento y comunicación/revisión. Registra evidencia individual. La propuesta funciona con pizarra, cuaderno y materiales disponibles; la conectividad no es requisito. En cursos numerosos usa respuestas simultáneas, estaciones y grupos temporales. Considera diversidad lingüística, cultural, sensorial y motriz.
