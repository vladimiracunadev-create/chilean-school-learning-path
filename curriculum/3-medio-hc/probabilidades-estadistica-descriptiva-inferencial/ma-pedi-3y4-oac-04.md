### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a distinguir parámetro de estadístico, a identificar los supuestos de una inferencia y a calcular y usar el error estándar de la media muestral.

**Lo que ya debo saber.** Sé calcular la media y la desviación estándar de una muestra. Sé estandarizar y usar la tabla de la normal. Sé qué es una muestra aleatoria.

**Explicación.**

Inferir es usar los datos de una muestra para sacar conclusiones sobre la población, aceptando que hay incertidumbre. El valor que describe a la población (como la media μ o la varianza σ²) es un parámetro y casi siempre es desconocido. El valor calculado con la muestra (como x̄ o s²) es un estadístico y sirve como estimación. Cada muestra aleatoria distinta da un estadístico distinto, por lo que x̄ tiene su propia distribución.

Si la variable es normal con parámetros μ y σ, la media muestral de n datos independientes también es normal, con media μ y desviación estándar σ ÷ √n. Esa desviación se llama error estándar y mide cuánto varían las medias muestrales de un mismo tamaño. Como n está en el denominador dentro de una raíz, para reducir el error estándar a la mitad hay que cuadruplicar el tamaño de la muestra.

Toda inferencia descansa en supuestos que hay que declarar: la muestra es aleatoria (cada integrante tuvo la misma posibilidad), los datos son independientes y la variable se distribuye de forma normal (se revisa, por ejemplo, con un histograma en forma de campana). Una muestra grande, pero escogida por conveniencia, no arregla un sesgo de selección: la aleatoriedad importa más que el tamaño.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| parámetro | valor que describe a la población, como μ |
| estadístico | valor calculado con la muestra, como x̄ |
| error estándar | desviación estándar de la media muestral, σ ÷ √n |
| muestra aleatoria | muestra elegida al azar, donde todos tienen la misma posibilidad |
| supuesto de normalidad | condición de que la variable tiene distribución normal |
| estimación | valor de un estadístico usado para aproximar un parámetro |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Error estándar*

Problema: Una variable normal de ejemplo tiene σ = 20 y se toma una muestra de n = 25. ¿Cuál es el error estándar de x̄?

1. Calcula √n: √25 = 5.
2. Divide: σ ÷ √n = 20 ÷ 5 = 4.

Respuesta: Error estándar = 4

*Ejemplo 2. Probabilidad para una media muestral*

Problema: X ~ N(50; 10) y n = 25. Calcula P(x̄ > 53).

1. Error estándar: 10 ÷ 5 = 2. Luego z = (53 − 50) ÷ 2 = 1,5.
2. P(x̄ > 53) = 1 − Φ(1,5) = 1 − 0,9332 = 0,0668.

Respuesta: P(x̄ > 53) = 0,0668

**Errores frecuentes y cómo reconocerlos**

- **Error:** Usar σ en lugar de σ ÷ √n al estandarizar una media muestral. **Por qué ocurre:** La media muestral varía menos que un dato individual. **Cómo corregirlo:** Calcula primero el error estándar y úsalo como denominador de z.
- **Error:** Creer que una muestra más grande siempre es mejor, aunque se haya elegido sin azar. **Por qué ocurre:** El tamaño no corrige un sesgo de selección. **Cómo corregirlo:** Verifica primero que la muestra sea aleatoria.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a construir e interpretar un intervalo de confianza para la media con σ conocida, y a ver cómo cambia con el nivel de confianza y el tamaño de la muestra.

**Lo que ya debo saber.** Sé calcular el error estándar. Sé qué es el valor z de una normal. Sé calcular x̄ ± algo.

**Explicación.**

Un intervalo de confianza es un rango de valores plausibles para un parámetro, construido con los datos de una muestra. Para la media μ con σ conocida, se calcula x̄ ± E, donde el margen de error es E = z · σ ÷ √n. El valor z depende del nivel de confianza: 1,645 para 90 %, 1,96 para 95 % y 2,576 para 99 %. El intervalo se puede escribir con la fórmula x̄ ± E o como un rango [a, b]; son dos formas de decir lo mismo, y el centro es siempre x̄.

La interpretación correcta es cuidadosa. Un nivel de confianza de 95 % significa que si repitiéramos muchas veces el muestreo y construyéramos el intervalo de la misma forma, cerca del 95 % de esos intervalos contendría a μ. No significa que el 95 % de los datos esté dentro del intervalo ni que x̄ tenga 95 % de probabilidad de estar dentro (el centro siempre está dentro). μ es un valor fijo: lo que varía de muestra a muestra es el intervalo.

El ancho del intervalo es 2E y depende de tres cosas: sube con el nivel de confianza (más confianza, más ancho), sube con σ y baja con n. Para dejar el margen de error en un valor E dado, se necesita al menos n = (z · σ ÷ E)² datos, redondeado hacia arriba. Como el error estándar baja con la raíz de n, reducir el margen a la mitad exige cuadruplicar la muestra.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| intervalo de confianza | rango de valores plausibles para un parámetro, construido con una muestra |
| nivel de confianza | porcentaje de intervalos construidos así que contendrían al parámetro |
| margen de error E | z · σ ÷ √n: distancia del centro a cada extremo |
| valor crítico z | número que depende del nivel de confianza: 1,645; 1,96 o 2,576 |
| ancho del intervalo | distancia entre los extremos, que es 2E |
| estimación puntual | un solo valor, como x̄, usado para estimar μ |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Construir un intervalo*

Problema: Una variable normal de ejemplo tiene σ = 10; con n = 25 se obtiene x̄ = 50. Construye el IC al 95 %.

1. Error estándar: 10 ÷ 5 = 2. Margen: E = 1,96 × 2 = 3,92.
2. Intervalo: 50 − 3,92 = 46,08 y 50 + 3,92 = 53,92.

Respuesta: IC al 95 %: [46,08; 53,92]

*Ejemplo 2. Recuperar la media y el margen*

Problema: Un IC al 95 % de ejemplo es [38, 46]. ¿Cuál fue x̄ y cuál el margen de error?

1. El centro es la media muestral: (38 + 46) ÷ 2 = 42.
2. El margen es la mitad del ancho: (46 − 38) ÷ 2 = 4.

Respuesta: x̄ = 42 y E = 4

**Errores frecuentes y cómo reconocerlos**

- **Error:** Usar σ en vez de σ ÷ √n al calcular el margen de error. **Por qué ocurre:** El margen depende del error estándar de la media, no de la dispersión de los datos individuales. **Cómo corregirlo:** Calcula primero σ ÷ √n y recién después multiplica por z.
- **Error:** Interpretar «95 %» como el porcentaje de los datos que cae dentro del intervalo. **Por qué ocurre:** El intervalo es para la media μ, no para los datos individuales. **Cómo corregirlo:** Di: «el método captura a μ en cerca del 95 % de las muestras».

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a plantear y resolver una prueba de hipótesis para la media con σ conocida, y a escribir una conclusión que no diga más de lo que muestran los datos.

**Lo que ya debo saber.** Sé calcular el error estándar. Sé estandarizar con z. Sé qué es un intervalo de confianza.

**Explicación.**

Una prueba de hipótesis decide si los datos de una muestra son compatibles con una afirmación sobre la población. La afirmación que se evalúa es la hipótesis nula H0 y siempre incluye la igualdad (por ejemplo, μ = 500). La hipótesis alternativa H1 es lo que se acepta si los datos contradicen a H0: puede ser bilateral (μ ≠ 500) o unilateral (μ < 500 o μ > 500), según lo que interese detectar.

El procedimiento tiene cinco pasos: plantear H0 y H1; fijar el nivel de significancia α (la probabilidad máxima que aceptamos de rechazar H0 cuando es verdadera, comúnmente 0,05); calcular el estadístico z = (x̄ − μ0) ÷ (σ ÷ √n); comparar con el valor crítico (1,96 para bilateral al 5 %); y decidir. Si |z| supera el valor crítico, se rechaza H0; si no, no se rechaza. Se rechaza cuando el resultado habría sido muy poco probable si H0 fuera verdadera.

La conclusión se escribe en el contexto del problema y con cuidado. Rechazar H0 significa que hay evidencia en su contra al nivel α. No rechazar H0 no significa que sea verdadera: solo que los datos no dieron evidencia suficiente. Además, esto depende de los supuestos: muestra aleatoria, independencia y normalidad. Una hoja de cálculo o una calculadora estadística puede entregar z y el valor crítico, pero la decisión de qué hipótesis plantear y cómo concluir es tuya.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| hipótesis nula H0 | afirmación con igualdad que se pone a prueba |
| hipótesis alternativa H1 | afirmación que se acepta si se rechaza H0 |
| estadístico de prueba | valor z calculado con la muestra |
| nivel de significancia α | probabilidad máxima de rechazar H0 siendo verdadera |
| valor crítico | límite que separa rechazar de no rechazar H0 |
| región de rechazo | valores del estadístico para los que se rechaza H0 |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Rechazar H0*

Problema: H0: μ = 60, con σ = 9 y n = 36; se observa x̄ = 63. Prueba bilateral al 5 %.

1. Error estándar: 9 ÷ 6 = 1,5. Estadístico: z = (63 − 60) ÷ 1,5 = 2.
2. Como |2| > 1,96, se rechaza H0.

Respuesta: Se rechaza H0: hay evidencia de que μ no es 60

*Ejemplo 2. No rechazar H0*

Problema: H0: μ = 60, con σ = 9 y n = 36; se observa x̄ = 61. Prueba bilateral al 5 %.

1. Error estándar: 1,5. Estadístico: z = (61 − 60) ÷ 1,5 ≈ 0,67.
2. Como 0,67 < 1,96, no se rechaza H0.

Respuesta: No se rechaza H0: los datos no dan evidencia suficiente en su contra

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir «se acepta H0» cuando |z| no supera el valor crítico. **Por qué ocurre:** No rechazar no demuestra que H0 sea verdadera, solo que faltó evidencia. **Cómo corregirlo:** Escribe «no hay evidencia suficiente para rechazar H0».
- **Error:** Usar σ en vez de σ ÷ √n en el denominador de z. **Por qué ocurre:** El estadístico compara x̄ y no un dato individual. **Cómo corregirlo:** Divide por el error estándar.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a relacionar intervalos de confianza y pruebas de hipótesis, a interpretar el valor p y a reconocer los errores tipo I y tipo II al justificar una inferencia.

**Lo que ya debo saber.** Sé construir un intervalo de confianza para μ. Sé realizar una prueba de hipótesis para μ. Sé leer la tabla de la normal.

**Explicación.**

Un intervalo de confianza y una prueba de hipótesis bilateral cuentan la misma historia. Si el valor μ0 de H0 queda fuera del intervalo de confianza de nivel 1 − α, la prueba bilateral con nivel α rechaza H0; si queda dentro, no la rechaza. En la ficha, el intervalo al 95 % es [480,2; 499,8]; como 500 queda fuera, la prueba rechaza H0, igual que con z = −2. El intervalo, además, informa qué valores son plausibles.

El valor p resume qué tan extremo es el resultado si H0 fuera verdadera. Con z = −2, p = 2 × (1 − 0,9772) = 0,0456. Como 0,0456 es menor que 0,05, se rechaza H0 al 5 %; pero con α = 0,01 no se rechazaría. El valor p no es la probabilidad de que H0 sea verdadera: es una probabilidad calculada suponiendo que H0 es verdadera.

Toda decisión puede equivocarse. El error tipo I es rechazar H0 cuando era verdadera; su probabilidad es α. El error tipo II es no rechazar H0 cuando era falsa; su probabilidad es β. Bajar α reduce el error tipo I pero aumenta β si todo lo demás queda igual. La forma de reducir ambos errores a la vez es aumentar el tamaño de la muestra. Justificar una inferencia incluye decir qué error sería más grave en ese contexto.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| valor p | probabilidad de un resultado tan extremo o más, suponiendo H0 verdadera |
| error tipo I | rechazar H0 siendo verdadera; su probabilidad es α |
| error tipo II | no rechazar H0 siendo falsa; su probabilidad es β |
| potencia | probabilidad de rechazar H0 cuando es falsa, igual a 1 − β |
| equivalencia IC–prueba | μ0 fuera del IC de nivel 1 − α implica rechazar H0 |
| evidencia | datos que respaldan o contradicen una afirmación |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Intervalo y prueba juntos*

1. Error estándar: 2; margen 1,96 × 2 = 3,92; IC = [58,08; 65,92].

Respuesta: No se rechaza H0: 65 es plausible

*Ejemplo 2. Calcular el valor p*

Problema: En una prueba bilateral, z = 1,5. Calcula p y decide al 5 %.

1. p = 2 × (1 − Φ(1,5)) = 2 × (1 − 0,9332) = 0,1336.
2. Como 0,1336 > 0,05, no se rechaza H0.

Respuesta: p = 0,1336: no se rechaza H0

**Errores frecuentes y cómo reconocerlos**

- **Error:** Decir que un valor p de 0,03 significa que H0 tiene 3 % de probabilidad de ser verdadera. **Por qué ocurre:** El valor p se calcula suponiendo que H0 es verdadera; no es la probabilidad de H0. **Cómo corregirlo:** Di: «si H0 fuera verdadera, un resultado así de extremo ocurriría cerca del 3 % de las veces».
- **Error:** Creer que bajar α reduce todos los errores. **Por qué ocurre:** Al exigir más evidencia, se rechaza menos y aumenta el error tipo II. **Cómo corregirlo:** Para reducir ambos errores, aumenta el tamaño de la muestra.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a hacer inferencias sobre la media cuando σ es desconocida (con t) y sobre la varianza (con chi cuadrado), y a comparar los resultados y sus supuestos.

**Lo que ya debo saber.** Sé construir un IC para μ con σ conocida. Sé calcular s y s² de una muestra. Sé leer una tabla de valores críticos.

**Explicación.**

En la práctica σ casi nunca se conoce y se estima con la desviación estándar muestral s. Entonces el estadístico (x̄ − μ) ÷ (s ÷ √n) ya no sigue una normal, sino una distribución t de Student con n − 1 grados de libertad (gl). La t es parecida a la normal, pero con colas más pesadas, para reflejar la incertidumbre extra de estimar σ; al aumentar n se acerca a la normal. El intervalo para μ queda x̄ ± t · s ÷ √n, con el valor t de una tabla, y es algo más ancho que el de σ conocida.

Para estimar la varianza σ² (o la desviación σ), si los datos son normales, la cantidad (n − 1) · s² ÷ σ² sigue una distribución chi cuadrado con n − 1 grados de libertad. Esta distribución no es simétrica, así que el intervalo de confianza para σ² no está centrado en s²: va desde (n − 1) · s² ÷ χ²superior hasta (n − 1) · s² ÷ χ²inferior. Para obtener un intervalo para σ se saca raíz cuadrada a ambos extremos.

Comprobar y comparar: antes de usar estos intervalos hay que revisar el supuesto de normalidad (por ejemplo, con un histograma sin asimetría fuerte ni valores extremos); si no se cumple, el intervalo puede ser engañoso. Un intervalo para σ que contiene un valor de referencia no permite afirmar que lo cumple ni que no lo cumple. Las tablas de t y de chi cuadrado, o una calculadora estadística, entregan los valores críticos, pero la interpretación sigue siendo tuya.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| distribución t de Student | modelo para la media cuando σ se estima con s; depende de los grados de libertad |
| grados de libertad | n − 1 en estos procedimientos |
| chi cuadrado | distribución usada para inferencias sobre la varianza |
| IC para σ² | intervalo de confianza para la varianza |
| asimetría | forma no simétrica de una distribución, como la chi cuadrado |
| supuesto de normalidad | condición que se revisa antes de usar t o chi cuadrado |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. IC para la media con t*

Problema: n = 9, x̄ = 30 y s = 6. Con 8 gl, t para 95 % = 2,306. Construye el IC para μ.

1. Error estándar estimado: s ÷ √n = 6 ÷ 3 = 2. Margen: 2,306 × 2 = 4,612.
2. Intervalo: 30 − 4,612 = 25,388 y 30 + 4,612 = 34,612.

Respuesta: IC al 95 %: [25,388; 34,612]

*Ejemplo 2. IC para la varianza*

Problema: n = 9 y s = 3, así que s² = 9. Con 8 gl, los valores chi cuadrado son 17,535 y 2,180. Construye el IC al 95 % para σ².

1. (n − 1) · s² = 8 × 9 = 72.
2. Extremos: 72 ÷ 17,535 ≈ 4,106 y 72 ÷ 2,180 ≈ 33,028.

Respuesta: IC al 95 % para σ²: [4,106; 33,028]

**Errores frecuentes y cómo reconocerlos**

- **Error:** Usar z = 1,96 con una muestra pequeña y σ estimada con s. **Por qué ocurre:** Ignora la incertidumbre extra de estimar σ y da un intervalo demasiado angosto. **Cómo corregirlo:** Usa t con n − 1 grados de libertad.
- **Error:** Centrar el IC de la varianza en s² sumando y restando un margen. **Por qué ocurre:** La chi cuadrado es asimétrica y el intervalo no es simétrico. **Cómo corregirlo:** Calcula cada extremo con su valor chi cuadrado.
