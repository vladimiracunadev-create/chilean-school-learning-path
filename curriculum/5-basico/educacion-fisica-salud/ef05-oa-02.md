# EF05 OA 02 — Tácticas para resolver problemas de juego
| Nivel | Asignatura | Tema/eje | Cobertura | Dosificación |
|---|---|---|---|---|
| 5° básico | Educación Física y Salud | Habilidades motrices | formacion-general-comun | 5 clases de 90 min |

## Qué se debe aprender
> Ejecutar juegos colectivos y deportes, creando tácticas y estrategias y demostrando formas para resolver un problema en relación con el espacio, el objeto y los adversarios; por ejemplo: dar tres pases en cinco segundos o dar tres pasos y dar un pase a un compañero.

> **Derechos y procedencia:** el código y la redacción del OA anterior proceden de
> Currículum Nacional (MINEDUC) y se reproducen con enlace y fecha de consulta para
> trazabilidad. No se declaran obra del proyecto ni quedan cubiertos por la licencia
> CC BY-NC-SA 4.0 del contenido pedagógico original. Consulta
> [LICENSING.md](../../../LICENSING.md).

**Explicación pedagógica.** Tácticas para resolver problemas de juego avanza desde combinar habilidades motrices, autocuidado y juego limpio desarrollados en 4° básico mediante decisiones situadas. Cada clase cambia la evidencia y forma de participación, y enfrenta la confusión «en tácticas para resolver problemas de juego, comparar cuerpos o rendimiento entre estudiantes».

**Antes de comenzar.** combinar habilidades motrices, autocuidado y juego limpio desarrollados en 4° básico

**Vocabulario explícito:** control, estrategia, intensidad, seguridad, cooperación, regulación, evidencia, autocuidado.

### Clase 1 de 5: Reconocer meta y condiciones de seguridad · Tácticas para resolver problemas de juego {#cl-04620}

**Meta para estudiantes:** Hoy desarrollaré «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego» y mostraré una decisión propia con evidencia.

| Momento | Tiempo | Acción docente y experiencia |
|---|---:|---|
| Inicio | 10 min | Demuestra a velocidad de observación una situación de «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego» usando estaciones, reglas visibles, implementos seguros y variantes accesibles para tácticas para resolver problemas de juego. El grupo identifica meta, espacio, señal de detención y condición de seguridad. |
| Modelado | 20 min | Ejecuta lentamente reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego y nombra mirada, apoyos, trayectoria, fuerza y regulación. Contrasta control con rapidez y aborda «en tácticas para resolver problemas de juego, comparar cuerpos o rendimiento entre estudiantes» sin presentar un cuerpo ideal. |
| Práctica guiada | 25 min | Practican «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego» en estaciones breves, sin eliminación, con distancia suficiente y variantes equivalentes; la retroalimentación se refiere a control y seguridad. La retroalimentación vuelve al criterio propio de «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego» antes del segundo intento. |
| Desempeño individual | 25 min | Resuelve una variante nueva de «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego»; elige nivel, distancia, implemento o ritmo, ejecútala con seguridad y ajusta desde su propia evidencia. La evidencia se juzga por el logro de «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego» y con evidencia propia. |
| Cierre | 10 min | Demuestra o representa la decisión usada en «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego» y nombra una señal corporal, espacial o reglamentaria que guio el ajuste. La respuesta final debe permitir comprobar «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego». |

### Insumo concreto y consigna

**Recurso listo para usar:** Estación delimitada de 4 × 4 m, cuatro conos y cronómetro: 50 s de acción, 50 s de pausa, tres intentos; variante sin desplazamiento disponible.

**Consigna exacta:** Practica «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego» priorizando control, distancia segura y autorregulación; registra una decisión técnica y una señal corporal antes y después.

**Referencia para modelar y corregir:** Se considera logrado cuando mantiene control y seguridad en dos intentos, ajusta intensidad a una señal corporal y explica una decisión; velocidad sola no acredita logro.

**Apoyo en el mismo OA:** Ajusta espacio, altura, distancia, velocidad, implemento, contacto o rol; conserva la habilidad y ofrece ensayo privado sin comparar cuerpos ni rendimiento.

**Profundización:** Combina otra habilidad o cambia dirección, ritmo, oposición o regla manteniendo control, acceso y seguridad.

**Evidencia:** Desempeño individual de «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego» con control, elección de variante y autoexplicación del ajuste.

**Criterios de éxito:** resuelve la consigna exacta de «reconocer meta y condiciones de seguridad · tácticas para resolver problemas de juego»; usa al menos dos datos, rasgos o evidencias del insumo concreto; explica una decisión y revisa su respuesta ante una condición nueva.

**Decisión posterior:** Avanza cuando decisión, evidencia y explicación coinciden; si no, cambia el acceso o modela otro caso y vuelve a recoger evidencia sin etiquetar al estudiante.

**Adaptación a 45 minutos:** Conserva situación específica, modelado, práctica guiada, evidencia individual y cierre; reduce cantidad o turnos, no el criterio disciplinar.

**Tarea breve y flexible:** Observa, practica o registra una versión breve y segura con recursos disponibles. No requiere compras, internet, datos personales ni exposición familiar, corporal o cultural.

**Actividades complementarias (opcionales):**
- Recuperación: aísla una decisión o pista y vuelve luego a la tarea completa.
- Análisis de error: revisa un caso ficticio que muestra esta confusión: en tácticas para resolver problemas de juego, comparar cuerpos o rendimiento entre estudiantes.
- Transferencia: cambia contexto, material, interlocutor, espacio o fuente y explica qué debe adaptarse.

**Control de dificultades en el aula**

|---|---|---|

| En tácticas para resolver problemas de juego, comparar cuerpos o rendimiento entre estudiantes | Ajusta espacio, altura, distancia, velocidad, implemento, contacto o rol; conserva la habilidad y ofrece ensayo privado sin comparar cuerpos ni rendimiento. | Resuelve un caso nuevo sin repetir la confusión. |
| Se inhibe, queda expuesto o no accede al formato | Reduce exposición y ofrece una vía equivalente de participación, manteniendo el objetivo. | Produce evidencia propia mediante una vía accesible y segura. |
