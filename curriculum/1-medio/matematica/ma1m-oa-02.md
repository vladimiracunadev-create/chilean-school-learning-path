### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a leer y calcular potencias cuya base es un número racional, con exponente natural. Sirve para áreas, volúmenes y repeticiones de factores.

**Lo que ya debo saber.** Sé qué es una potencia de base entera. Sé multiplicar racionales.

**Explicación.**

Una potencia a^n, con n natural, es multiplicar la base a por sí misma n veces. La base es el factor que se repite y el exponente dice cuántas veces. Por ejemplo, (−3)^4 = (−3)·(−3)·(−3)·(−3) = 81.

Con una base fraccionaria, el exponente afecta a numerador y denominador: (2/5)^2 = 4/25. Con una base decimal se multiplica el decimal: 0,5^3 = 0,125. Cuidado con los paréntesis: (−2)^2 = 4, pero −2^2 = −(2^2) = −4.

El signo depende del exponente cuando la base es negativa. Con exponente par el resultado es positivo, porque los signos negativos se juntan en parejas. Con exponente impar es negativo. Esto ayuda a estimar y a revisar un resultado.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| base | número que se multiplica por sí mismo |
| exponente | número que indica cuántas veces se repite la base |
| potencia | producto de factores iguales |
| exponente par | exponente que es un número par, como 2 o 4 |
| paréntesis | signo que agrupa y define a qué número afecta el exponente |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Base negativa*

Problema: Calcula (−2/3)^3.

1. Exponente impar: el resultado será negativo.
2. Elevo numerador y denominador: 2^3 = 8 y 3^3 = 27.

Respuesta: −8/27

*Ejemplo 2. Cuidado con el paréntesis*

Problema: Compara (−3)^2 y −3^2.

1. (−3)^2 = (−3)·(−3) = 9.
2. −3^2 = −(3·3) = −9, porque el exponente afecta solo al 3.

Respuesta: 9 y −9

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir (−4)^2 = −16. **Por qué ocurre:** Se aplicó el signo menos fuera del exponente, y el paréntesis dice que el −4 completo se multiplica por sí mismo. **Cómo corregirlo:** (−4)·(−4) = 16.
- **Error:** Calcular (2/3)^2 = 4/3. **Por qué ocurre:** Se elevó solo el numerador. **Cómo corregirlo:** El exponente afecta ambos términos: 4/9.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé qué significan el exponente cero y los exponentes negativos. Sirve para escribir números muy pequeños y para completar patrones de potencias.

**Lo que ya debo saber.** Sé calcular potencias con exponente natural. Sé hallar el inverso multiplicativo de una fracción.

**Explicación.**

Mira el patrón de las potencias de 2: 2^3 = 8, 2^2 = 4, 2^1 = 2. Cada vez que el exponente baja 1, el resultado se divide por 2. Si el patrón sigue, 2^0 = 1, luego 2^-1 = 1/2 y 2^-2 = 1/4.

Por eso se define a^0 = 1 para cualquier a distinto de 0. Para exponentes negativos, a^-n = 1/a^n. También puedes invertir la base: (a/b)^-n = (b/a)^n. Así, (2/3)^-2 = (3/2)^2 = 9/4.

Un exponente negativo no hace negativo el resultado: indica el inverso. Por ejemplo, 3^-2 = 1/9, que es positivo. Con base negativa, el signo depende de si el exponente es par o impar: (−2)^-3 = 1/(−2)^3 = −1/8. El 0 no puede tener exponente negativo ni cero.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| exponente cero | exponente que da 1 si la base no es 0 |
| exponente negativo | indica el inverso de la potencia positiva |
| inverso | número que multiplicado por otro da 1 |
| potencia de 10 | potencia de base 10, como 10^-3 |
| patrón | regularidad que permite continuar una serie |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Completar un patrón*

Problema: Continúa: 5^2 = 25, 5^1 = 5, 5^0 = ?, 5^-1 = ?

1. Cada paso divide por 5: 25 ÷ 5 = 5, 5 ÷ 5 = 1.
2. Luego 1 ÷ 5 = 1/5.

Respuesta: 5^0 = 1 y 5^-1 = 1/5

*Ejemplo 2. Base fraccionaria*

Problema: Calcula (3/4)^-2.

1. Invierto la base: (4/3)^2.
2. Elevo: 16/9.

Respuesta: 16/9

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir 5^-2 = −25. **Por qué ocurre:** Se creyó que el exponente negativo da un número negativo. **Cómo corregirlo:** El exponente negativo indica el inverso: 5^-2 = 1/25.
- **Error:** Escribir 7^0 = 0. **Por qué ocurre:** Se confundió el exponente 0 con multiplicar por 0. **Cómo corregirlo:** Según el patrón, 7^0 = 1.

**Explicación.**

Si las bases son iguales, al multiplicar potencias se suman los exponentes: a^m·a^n = a^(m+n). Al dividir se restan: a^m ÷ a^n = a^(m−n). Y una potencia de potencia multiplica: (a^m)^n = a^(m·n). Por ejemplo, 2^5·2^-3 = 2^2 = 4.

Cuando el exponente se aplica a un producto o a un cociente, afecta a cada factor: (a·b)^n = a^n·b^n y (a/b)^n = a^n/b^n. Así, (2·5)^3 = 2^3·5^3 = 8·125 = 1.000.

Estas propiedades solo valen con bases iguales en productos y cocientes. La suma no se simplifica así: 3^2 + 3^3 = 9 + 27 = 36, y no es 3^5. Una buena revisión es sustituir por números chicos y comprobar.

**Explicación.**

Para simplificar una expresión con potencias, primero busca una base común. Por ejemplo, 4 = 2^2 y 8 = 2^3, entonces 4^2 = 2^4. Después aplica las propiedades de potencias y escribe el resultado con exponentes positivos si es posible.

Para comparar potencias de la misma base mayor que 1, mayor exponente significa mayor valor: 2^3 > 2^-2. Si la base está entre 0 y 1 ocurre al revés: (1/2)^3 < (1/2)^2. Cuando las bases son distintas, convierte a una base común o calcula los valores.

Los exponentes negativos permiten escribir decimales pequeños: 0,01 = 10^-2 y 0,001 = 10^-3. Para revisar, calcula el valor aproximado de la expresión original y de la simplificada: deben coincidir.

| Palabra | Qué significa |
|---|---|
| base común | base igual en todas las potencias de la expresión |
| simplificar | escribir una expresión de forma más corta |
| comparar | decidir cuál valor es mayor |
| potencia de 10 | potencia de base 10 |
| valor aproximado | cálculo cercano al exacto |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Simplificar con base común*

Problema: Simplifica (2^3·4^2) ÷ 2^5.

2. Numerador: 2^3·2^4 = 2^7.

**Errores frecuentes y cómo reconocerlos**

- **Error:** Decir que 3^-4 es mayor que 3^-2 porque 4 es mayor que 2. **Por qué ocurre:** Se miró el 4 sin su signo; con exponente negativo el valor baja: 3^-4 = 1/81 y 3^-2 = 1/9. **Cómo corregirlo:** Con base mayor que 1, mayor exponente da mayor valor, y −2 es mayor que −4: 3^-2 es la mayor.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a modelar crecimiento y decrecimiento con potencias, y a comprobar si una situación crece o decrece. Sirve para analizar poblaciones, saldos y cantidades que cambian por factor.

**Lo que ya debo saber.** Sé calcular potencias con exponente entero. Sé interpretar un factor como 2 (se duplica) o 1/2 (queda la mitad).

**Explicación.**

Cuando una cantidad se multiplica por el mismo factor en cada período, se puede modelar con una potencia. Si la cantidad inicial es C y el factor es f, después de t períodos hay C·f^t. Por ejemplo, 300 bacterias que se duplican cada hora son 300·2^t.

Si el factor es mayor que 1, la cantidad crece. Si está entre 0 y 1, decrece. Por ejemplo, el factor 1/2 deja la mitad cada período, y el factor 0,9 conserva el 90 % de la cantidad. Un exponente negativo representa el pasado: C·f^-1 es la cantidad un período antes.

Para comprobar un modelo, calcula los primeros períodos a mano y compara. Si en t = 0 la fórmula no devuelve la cantidad inicial, hay un error, porque f^0 = 1. Revisa también que el sentido coincida: si debería decrecer, el resultado debe ir bajando.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| factor de cambio | número por el que se multiplica la cantidad en cada período |
| cantidad inicial | valor al comienzo, cuando t = 0 |
| crecimiento | aumento cuando el factor es mayor que 1 |
| decrecimiento | disminución cuando el factor está entre 0 y 1 |
| período | intervalo de tiempo en que se aplica el factor |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Crecimiento*

Problema: Un cultivo de ejemplo de 300 bacterias se duplica cada hora. ¿Cuántas hay a las 4 horas?

1. Factor 2, cantidad inicial 300.
2. 300·2^4 = 300·16 = 4.800.

Respuesta: 4.800 bacterias

*Ejemplo 2. Decrecimiento*

Problema: Una sustancia de ejemplo de 80 g queda con la mitad cada día. ¿Cuánto queda a los 3 días?

1. Factor 1/2, cantidad inicial 80.
2. 80·(1/2)^3 = 80·1/8 = 10.

Respuesta: 10 g

**Errores frecuentes y cómo reconocerlos**

- **Error:** Calcular 5·3^3 como (5·3)^3. **Por qué ocurre:** Se aplicó el exponente también a la cantidad inicial. **Cómo corregirlo:** El exponente va solo en el factor: 5·27.
- **Error:** Decir que (1/2)^t crece porque 2 es mayor que 1. **Por qué ocurre:** Se miró el denominador y no el valor del factor. **Cómo corregirlo:** 1/2 es menor que 1, así que cada período queda menos.
