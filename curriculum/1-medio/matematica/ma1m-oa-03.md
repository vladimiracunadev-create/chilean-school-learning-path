### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a multiplicar binomios y a ver ese producto como el área de un rectángulo. Sirve para escribir áreas con medidas desconocidas.

**Lo que ya debo saber.** Sé la propiedad distributiva con números. Sé reducir términos semejantes.

**Explicación.**

Un binomio es una expresión de dos términos, como x + 3. Para multiplicar (x + 3)(x + 2), multiplica cada término del primer binomio por cada término del segundo: x·x + x·2 + 3·x + 3·2. Eso da x² + 2x + 3x + 6, y al reducir términos semejantes queda x² + 5x + 6.

Esto se ve en un rectángulo de largo x + 3 y ancho x + 2. Se divide en cuatro partes: un cuadrado de área x², dos rectángulos de áreas 2x y 3x, y un rectángulo de área 3·2 = 6. La suma de las cuatro áreas es el área total.

Los términos semejantes tienen la misma parte literal, como 2x y 3x, y se reducen sumando sus coeficientes. En un problema de áreas, x es una medida de longitud, así que debe ser un número positivo. Siempre se puede comprobar una expresión reemplazando x por un número.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| binomio | expresión con dos términos, como x + 3 |
| término | parte de una expresión separada por + o − |
| términos semejantes | términos con la misma parte literal, como 2x y 5x |
| parte literal | letra con su exponente, como x² |
| desarrollar | multiplicar y reducir hasta obtener sumas de términos |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Producto de binomios*

Problema: Desarrolla (x + 3)(x + 2).

1. Multiplico cada término: x·x = x², x·2 = 2x, 3·x = 3x, 3·2 = 6.
2. Reduzco 2x + 3x = 5x.

Respuesta: x² + 5x + 6

*Ejemplo 2. Con un signo menos*

Problema: Desarrolla (x − 4)(x + 1).

1. x·x = x², x·1 = x, −4·x = −4x, −4·1 = −4.
2. Reduzco x − 4x = −3x.

Respuesta: x² − 3x − 4

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir (x + 3)(x + 2) = x² + 6. **Por qué ocurre:** Solo se multiplicaron los primeros y los últimos términos. **Cómo corregirlo:** Faltan los productos cruzados: 2x y 3x. El resultado es x² + 5x + 6.
- **Error:** Escribir (x − 1)(x + 6) = x² + 5x + 6. **Por qué ocurre:** Se ignoró el signo menos del segundo término. **Cómo corregirlo:** El último término es (−1)·6 = −6, y el resultado es x² + 5x − 6.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé el cuadrado de un binomio como un producto notable. Sirve para escribir áreas de cuadrados y calcular más rápido.

**Lo que ya debo saber.** Sé multiplicar dos binomios. Sé reducir términos semejantes.

**Explicación.**

El cuadrado de un binomio es (a + b)² = (a + b)(a + b). Al desarrollarlo queda a² + 2ab + b². Es un producto notable porque siempre tiene la misma forma. Por ejemplo, (x + 5)² = x² + 10x + 25.

En un cuadrado de lado a + b se ven cuatro regiones: un cuadrado de área a², otro de área b² y dos rectángulos de área ab. Por eso aparece 2ab. Si el binomio tiene resta, (a − b)² = a² − 2ab + b²: el término del medio es negativo, pero el último es positivo.

Un error frecuente es creer que (a + b)² = a² + b². Falta el doble producto 2ab. Puedes comprobarlo con números: (2 + 3)² = 25, pero 2² + 3² = 13. Además, los cuadrados sirven para el cálculo mental, como 103² = (100 + 3)² = 10.000 + 600 + 9.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| cuadrado de un binomio | binomio multiplicado por sí mismo |
| producto notable | producto cuyo desarrollo sigue siempre una regla fija |
| doble producto | el término 2ab que aparece en el desarrollo |
| trinomio | expresión de tres términos |
| cuadrado perfecto | número o expresión que es cuadrado de otra |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Suma al cuadrado*

Problema: Desarrolla (x + 6)².

1. a = x y b = 6.
2. a² = x², 2ab = 12x, b² = 36.

Respuesta: x² + 12x + 36

*Ejemplo 2. Resta al cuadrado*

Problema: Desarrolla (2x − 1)².

1. a = 2x y b = 1.
2. a² = 4x², 2ab = 4x con signo negativo, b² = 1.

Respuesta: 4x² − 4x + 1

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir (x + 3)² = x² + 9. **Por qué ocurre:** Falta el doble producto. **Cómo corregirlo:** (x + 3)² = x² + 6x + 9.
- **Error:** Escribir (x − 4)² = x² − 8x − 16. **Por qué ocurre:** El último término del cuadrado siempre es positivo. **Cómo corregirlo:** (−4)² = 16, entonces x² − 8x + 16.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé la suma por su diferencia y a transformar sumas en productos (factorizar). Sirve para simplificar y para calcular productos de forma rápida.

**Lo que ya debo saber.** Sé desarrollar el cuadrado de un binomio. Sé hallar pares de números que se multiplican.

**Explicación.**

La suma por su diferencia es (a + b)(a − b) = a² − b². Los términos cruzados se anulan, porque +ab y −ab suman 0. Por ejemplo, (x + 6)(x − 6) = x² − 36. Este producto sirve para multiplicar rápido: 51·49 = (50 + 1)(50 − 1) = 2.500 − 1 = 2.499.

También hay un producto con término común: (x + a)(x + b) = x² + (a + b)x + ab. Por ejemplo, (x + 2)(x + 7) = x² + 9x + 14. El coeficiente de x es la suma de los números y el último término es su producto.

Factorizar es el camino inverso: transformar una suma en producto. Para x² + 7x + 12 buscas dos números que se multipliquen 12 y sumen 7; son 3 y 4, entonces x² + 7x + 12 = (x + 3)(x + 4). Y x² − 49 = (x + 7)(x − 7). Se comprueba desarrollando.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| suma por diferencia | producto (a + b)(a − b) |
| diferencia de cuadrados | expresión a² − b² |
| factorizar | escribir una suma como producto |
| factor | expresión que se multiplica |
| término común | término que se repite en los dos binomios |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Factorizar diferencia de cuadrados*

Problema: Factoriza x² − 25.

1. x² = (x)² y 25 = 5².
2. Entonces es una diferencia de cuadrados: (x + 5)(x − 5).

Respuesta: (x + 5)(x − 5)

*Ejemplo 2. Factorizar un trinomio*

Problema: Factoriza x² + 8x + 15.

1. Busco dos números con producto 15 y suma 8: 3 y 5.
2. Compruebo: (x + 3)(x + 5) = x² + 8x + 15.

Respuesta: (x + 3)(x + 5)

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir (x + 4)(x − 4) = x² + 16. **Por qué ocurre:** Se olvidó el signo menos: los términos cruzados se anulan, pero 4·(−4) = −16. **Cómo corregirlo:** (x + 4)(x − 4) = x² − 16.
- **Error:** Factorizar x² + 25 como (x + 5)(x − 5). **Por qué ocurre:** Ese producto da x² − 25, no x² + 25. **Cómo corregirlo:** x² + 25 no se factoriza con estos binomios.

**Lo que aprenderé y para qué sirve.** Aprenderé a comparar estrategias para desarrollar y reducir expresiones algebraicas. Sirve para elegir el camino más corto y comprobar el resultado.

**Lo que ya debo saber.** Sé los productos notables. Sé reducir términos semejantes.

**Explicación.**

Para desarrollar un producto hay dos caminos. Puedes multiplicar término a término con la propiedad distributiva, o reconocer un producto notable y usar su regla. Reconocer (x + 5)² ahorra los cuatro productos y reduce errores.

Al reducir expresiones, desarrolla cada producto notable y luego junta los términos semejantes. Si restas un paréntesis, cambia todos sus signos: (x + 3)² − (x − 3)² = (x² + 6x + 9) − (x² − 6x + 9) = 12x. Es uno de los errores más frecuentes.

Para comprobar, reemplaza x por un número fácil, como 1 o 2, en la expresión original y en la reducida. Si los valores no coinciden, hay un error. Un solo número que coincida no prueba que esté bien, pero uno que no coincide prueba que está mal.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| reducir | simplificar una expresión juntando términos semejantes |
| comprobar | revisar con un valor numérico que dos expresiones coinciden |
| expresión equivalente | expresión que vale lo mismo para cualquier x |
| paréntesis precedido de menos | paréntesis que cambia el signo de todos sus términos |
| estrategia | camino elegido para resolver |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Reducir con resta*

Problema: Reduce (x + 3)² − (x − 3)².

1. Desarrollo: x² + 6x + 9 y x² − 6x + 9.
2. Resto cambiando los signos del segundo paréntesis: x² + 6x + 9 − x² + 6x − 9.
3. Reduzco: 12x.

Respuesta: 12x

*Ejemplo 2. Comprobar con un número*

Problema: Comprueba si (x + 1)² − 1 = x² + 2x con x = 3.

1. Lado izquierdo: 4² − 1 = 15.
2. Lado derecho: 9 + 6 = 15.

Respuesta: Coinciden, ambos valen 15

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir (x + 2)² − (x − 2)² = 0 porque «se parecen». **Por qué ocurre:** No se desarrolló: los dos cuadrados son distintos. **Cómo corregirlo:** x² + 4x + 4 − x² + 4x − 4 = 8x.
- **Error:** Escribir (x + 4)² − (x − 4)² = x² + 8x + 16 − x² − 8x + 16 = 32. **Por qué ocurre:** Al restar el segundo paréntesis no se cambiaron todos sus signos. **Cómo corregirlo:** −(x² − 8x + 16) = −x² + 8x − 16, y el total es 16x.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a completar el cuadrado de un binomio, escribiendo un trinomio como un cuadrado más o menos un número. Sirve para modelar áreas y para hallar mínimos.

**Lo que ya debo saber.** Sé desarrollar (x + a)². Sé factorizar x² + 2ax + a².

**Explicación.**

Completar el cuadrado es agregar el número que falta para formar un cuadrado de binomio. En x² + 6x falta 9, porque (x + 3)² = x² + 6x + 9. El número que falta es la mitad del coeficiente de x, elevada al cuadrado: (6 ÷ 2)² = 9.

Para no cambiar el valor se suma y se resta el mismo número: x² + 6x = (x² + 6x + 9) − 9 = (x + 3)² − 9. Con coeficiente negativo, x² − 8x = (x − 4)² − 16. Siempre se puede comprobar desarrollando.

Esta forma sirve para modelar. Como un cuadrado nunca es negativo, (x + 3)² vale al menos 0, entonces x² + 6x = (x + 3)² − 9 vale al menos −9. Ese mínimo ocurre cuando x = −3. También sirve para pasar de un área a un cuadrado más una parte que falta.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| completar el cuadrado | agregar lo necesario para formar (x + a)² |
| coeficiente | número que multiplica a una letra |
| mínimo | el menor valor que puede tomar una expresión |
| cuadrado perfecto | trinomio que es el cuadrado de un binomio |
| sumar y restar lo mismo | truco que no cambia el valor de la expresión |

**Ejemplos resueltos paso a paso**

2. Sumo y resto 9: x² + 6x + 9 − 9 = (x + 3)² − 9.

Respuesta: (x + 3)² − 9

*Ejemplo 2. Con coeficiente negativo*

Problema: Escribe x² − 8x en la forma (x − a)² − b.

2. x² − 8x + 16 − 16 = (x − 4)² − 16.

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir x² + 8x = (x + 4)². **Por qué ocurre:** Se agregó 16 pero no se restó. **Cómo corregirlo:** x² + 8x = (x + 4)² − 16.
- **Error:** Completar x² + 6x con 6. **Por qué ocurre:** Se usó el coeficiente completo, no su mitad. **Cómo corregirlo:** Se agrega (6 ÷ 2)² = 9.
