### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a distinguir si una situación crece de forma lineal o exponencial mirando su razón de cambio. Sirve para elegir el modelo correcto antes de predecir.

**Lo que ya debo saber.** Sé interpretar una tabla de valores. Sé calcular porcentajes y potencias.

**Explicación.**

En un cambio lineal, la variable aumenta o disminuye siempre la misma cantidad por cada paso: la diferencia entre valores consecutivos es constante. Por ejemplo, 5, 8, 11, 14 sube 3 cada vez. Su modelo es f(x) = m·x + n, y su gráfica es una recta.

En un cambio exponencial, la variable se multiplica siempre por el mismo número, llamado factor: el cociente entre valores consecutivos es constante. Por ejemplo, 3, 6, 12, 24 se multiplica por 2. Si el factor es mayor que 1 hay crecimiento; si está entre 0 y 1 hay decrecimiento.

Un aumento porcentual fijo es exponencial: subir 10 % cada mes equivale a multiplicar por 1,1. Aunque al inicio un crecimiento exponencial puede parecer lento, con el tiempo supera a cualquier crecimiento lineal. Para clasificar una tabla, calcula primero las diferencias y luego los cocientes.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| razón de cambio | cuánto cambia la variable de un paso al siguiente |
| crecimiento lineal | aumento con la misma diferencia en cada paso |
| crecimiento exponencial | aumento con el mismo factor en cada paso |
| factor | número por el que se multiplica en cada paso |
| decrecimiento | disminución del valor a medida que pasa el tiempo |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Reconocer lo lineal*

Problema: La tabla es t = 0, 1, 2, 3 con y = 5, 8, 11, 14. ¿Es lineal o exponencial?

1. Diferencias: 8 − 5 = 3, 11 − 8 = 3, 14 − 11 = 3, siempre iguales.
2. Cocientes: 8/5, 11/8, 14/11 no son iguales.

Respuesta: Es lineal, con razón de cambio 3

*Ejemplo 2. Reconocer lo exponencial*

Problema: La tabla es t = 0, 1, 2, 3 con y = 3, 6, 12, 24. ¿Qué tipo de cambio es?

1. Diferencias: 3, 6, 12, que no son constantes.
2. Cocientes: 6/3 = 2, 12/6 = 2, 24/12 = 2.

Respuesta: Es exponencial, con factor 2

**Errores frecuentes y cómo reconocerlos**

- **Error:** Decir que 2, 4, 6, 8 es exponencial porque «sube rápido». **Por qué ocurre:** Se confunde rapidez con tipo de cambio: aquí la diferencia es siempre 2. **Cómo corregirlo:** Mira diferencias y cocientes: diferencia constante es lineal.
- **Error:** Pensar que subir 10 % cada mes es subir siempre la misma cantidad. **Por qué ocurre:** El 10 % se calcula sobre un valor que cambia cada mes. **Cómo corregirlo:** Multiplica por 1,1 en cada paso; la cantidad que se suma crece.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a construir un modelo f(t) = a · bᵗ a partir de datos y a interpretar el valor inicial a y el factor b. Sirve para predecir valores y comprobar si el modelo calza con la situación.

**Lo que ya debo saber.** Sé distinguir cambio lineal y exponencial. Sé calcular potencias con calculadora.

**Explicación.**

Un modelo exponencial se escribe f(t) = a · bᵗ, donde a es el valor inicial (el valor en t = 0) y b es el factor de cambio por cada unidad de t. Si b > 1 el modelo crece y si 0 < b < 1 decrece. El valor de b debe ser positivo.

Para pasar de un porcentaje al factor, suma o resta el porcentaje a 1. Un aumento de 8 % da b = 1,08 y una disminución de 20 % da b = 0,8. Un error frecuente es usar 0,08 o 0,2 como factor: eso no representa el cambio acumulado.

Si conoces dos datos, el factor sale del cociente. Si f(0) = 200 y f(2) = 450, entonces b² = 450/200 = 2,25 y b = 1,5. Luego prueba el modelo con un tercer dato si lo tienes. Un buen modelo se revisa: ¿cumple los datos conocidos y tiene sentido en el contexto?

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| valor inicial | valor de la función cuando t = 0 |
| factor de cambio | número b por el que se multiplica en cada unidad de t |
| parámetro | número que define un modelo, como a y b |
| modelo | expresión matemática que describe una situación |
| depreciación | pérdida de valor con el tiempo |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Modelo desde un porcentaje*

Problema: Una población de ejemplo de 400 personas aumenta 5 % cada año. Escribe el modelo y calcula la población al cabo de 3 años.

1. Valor inicial a = 400 y factor b = 1 + 0,05 = 1,05.
2. Modelo: P(t) = 400 · 1,05ᵗ.
3. P(3) = 400 · 1,157625 = 463,05, que se redondea a 463 personas.

Respuesta: P(t) = 400 · 1,05ᵗ; P(3) ≈ 463

*Ejemplo 2. Modelo desde dos datos*

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé que el logaritmo deshace a la exponencial y lo usaré para despejar el tiempo en un modelo. Sirve para responder preguntas como «¿cuánto tiempo falta para llegar a cierto valor?».

**Lo que ya debo saber.** Sé calcular potencias de enteros. Sé despejar una incógnita en una ecuación simple.

**Explicación.**

El logaritmo en base b de un número x es el exponente al que hay que elevar b para obtener x: log_b(x) = y significa bʸ = x. Por ejemplo, log₂(32) = 5 porque 2⁵ = 32, y log₁₀(1.000) = 3 porque 10³ = 1.000. Sin base escrita, log significa base 10.

Exponencial y logaritmo son procesos inversos: log_b(bˣ) = x y b^(log_b x) = x. Así se despeja el exponente: de 3 · 2ᵗ = 96 sale 2ᵗ = 32, y entonces t = log₂(32) = 5. Se definen solo para x > 0, y con b > 0 distinto de 1.

Dos propiedades útiles: log_b(x · y) = log_b(x) + log_b(y) y log_b(xᵏ) = k · log_b(x). Cuidado: log_b(x + y) no es la suma de los logaritmos. También log_b(1) = 0 y log_b(b) = 1. Con calculadora puedes comprobar valores aproximados. Como son inversas, si el punto (x, y) está en la gráfica de y = bˣ, el punto (y, x) está en la gráfica de y = log_b(x).

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| logaritmo | exponente al que se eleva la base para obtener un número |
| base | número que se eleva en la potencia, como el 2 en 2⁵ |
| proceso inverso | operación que deshace otra |
| despejar | dejar la incógnita sola en un lado de la ecuación |
| exponente | número que indica cuántas veces se multiplica la base |

**Explicación.**

Cuando una publicación afirma que algo «crece exponencialmente», puedes comprobarlo con los datos: calcula los cocientes entre valores consecutivos. Si son casi constantes, el modelo exponencial es razonable; si las diferencias son las constantes, el cambio es lineal. Una afirmación que no calza con sus propios datos es una señal de alerta.

Para evaluar una fuente, revisa: quién la escribe y con qué experiencia, cuándo se publicó, si cita la fuente original (primaria) con enlace, si explica cómo se obtuvieron los datos y si busca vender algo. Que muchas cuentas repitan la misma cifra no la confirma si todas copian a una misma fuente.

También conviene mirar los gráficos: un eje vertical que no parte en cero puede exagerar un cambio pequeño. Contrasta siempre al menos dos fuentes independientes y anota las diferencias. Si no puedes verificar un dato, comunica el modelo con los límites y no como un hecho.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a comunicar una predicción con su modelo, sus supuestos, su dominio y sus límites. Sirve para dar una respuesta honesta, que diga hasta dónde se puede confiar en el modelo.

**Lo que ya debo saber.** Sé construir modelos exponenciales y usar logaritmos. Sé evaluar fuentes de información.

**Explicación.**

Una predicción completa tiene cuatro partes: el modelo (por ejemplo P(t) = 100 · 1,2ᵗ), el resultado con sus unidades (por ejemplo «619 individuos»), los supuestos (el factor se mantiene, no hay cambios externos) y el dominio, que es el conjunto de valores de t donde el modelo tiene sentido. Si t son semanas desde hoy, el dominio parte en t = 0.

Un crecimiento exponencial no puede seguir para siempre: los recursos, el espacio o el número de personas son finitos. Cuando el modelo predice más que la capacidad real, ya no es válido. Por eso se indica un límite y se evita extrapolar muy lejos de los datos, porque la incerteza aumenta.

Un decrecimiento exponencial como 1.000 · 0,5ᵗ se acerca a cero pero nunca lo alcanza exactamente. En contextos de conteo, el resultado se redondea a un entero con sentido. Siempre revisa si el resultado es razonable y explica en una frase cómo cambiaría la conclusión si cambia el factor.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| dominio | valores de la variable donde el modelo tiene sentido |
| extrapolar | predecir fuera del rango de los datos |
| supuesto | condición que se acepta para que el modelo valga |
| capacidad máxima | valor que la situación real no puede superar |
| redondear | aproximar a un valor con sentido en el contexto |

*Ejemplo 1. Predicción completa*

Problema: Una colonia de ejemplo tiene 100 individuos y aumenta 20 % por semana. Predice la semana 10 y declara supuestos y dominio.

1. Modelo: P(t) = 100 · 1,2ᵗ con t en semanas, t ≥ 0.
2. P(10) = 100 · 6,19… ≈ 619 individuos.
3. Supuestos: el factor 1,2 se mantiene y hay alimento y espacio suficientes.

Respuesta: Aproximadamente 619 individuos

**Actividad abierta · ejemplo de respuesta.** S(t) = 300 · 1,15ᵗ con t ≥ 0 en semanas. S(6) = 300 · 2,313… ≈ 694. Primera semana con más de 1.000: S(8) ≈ 918 y S(9) ≈ 1.055, así que la semana 9. Supuestos: el 15 % se mantiene y no hay cambios externos. Límite: el interés puede decaer.

**Criterios para evaluarla:** escribe el modelo con unidades; declara dominio, supuestos y límite; explica por qué predecir lejos es más incierto.

**Evidencias aceptables:** modelo y predicción; texto de supuestos y límites.

**Errores que conviene detectar:** no escribir el dominio; aceptar un resultado que no tiene sentido.

**Retroalimentación constructiva:** Si omite los límites, pide que escriba una situación real en que el 15 % semanal dejaría de cumplirse.

**Refuerzo.** Calcula la predicción de la semana 4 para 300 seguidores que crecen 15 % semanal y escribe un supuesto.

**Profundización.** Compara un modelo exponencial con uno que alcanza una capacidad máxima y explica cuándo cada uno es mejor.


**Apoyo en el mismo OA:** Reduce temporalmente el rango o la cantidad, conserva la relación matemática y permite material concreto, tabla, recta o dibujo antes del símbolo; después retorna al desafío original.

**Profundización:** Cambia una condición de tablas, gráficos y expresiones de crecimiento o decrecimiento en datos simulados de población, temperatura, intensidad o difusión digital con fuente y escala declaradas, predice el efecto y crea un contraejemplo que obligue a revisar la estrategia inicial.

**Evidencia:** Solución individual sobre comunicar predicciones, supuestos, dominio y límites del modelo con representación pertinente, razonamiento visible, unidad y comprobación.

**Criterios de éxito:** responde al foco matemático de la clase; usa una representación o estrategia pertinente; fundamenta y comprueba la solución.

**Decisión posterior:** Avanza si representación, cálculo y explicación coinciden; si no, identifica si la barrera está en el concepto, la representación, el procedimiento o la comprobación y reenseña con un caso diferente.

**Adaptación a 45 minutos:** Conserva el desafío, un modelado breve, práctica conjunta, evidencia individual y ticket; reduce repeticiones, no la demanda matemática.

**Tarea breve y flexible:** Crea o busca un ejemplo cotidiano seguro del foco y explícalo con dibujo, nota u oralidad. No requiere internet, impresión, compras ni datos familiares.

**Actividades complementarias (opcionales):**
- Recuperación: resolver un caso con menor carga y volver al original.
- Análisis de error: corregir un caso ficticio que muestra esta confusión: tratar cualquier variación como exponencial, extrapolar sin límites o usar el logaritmo como tecla sin interpretar base y dominio.
- Transferencia: cambiar una condición o representación y revisar la respuesta.

**Control de dificultades en el aula**

| Dificultad observable | Acción inmediata | Cómo comprobar si funcionó |
|---|---|---|
| Responde antes de examinar datos o representación | Pide señalar la evidencia que usará y anticipar cómo la comprobará. | La nueva respuesta muestra datos y comprobación pertinentes. |
| Tratar cualquier variación como exponencial, extrapolar sin límites o usar el logaritmo como tecla sin interpretar base y dominio | Vuelve a una representación concreta o pictórica, contrasta dos casos y retoma el desafío simbólico. | Resuelve un caso nuevo sin repetir la confusión y explica la diferencia. |
| Obtiene un resultado, pero no puede justificarlo | Solicita comparar con otra estrategia y nombrar el criterio decisivo. | La explicación permite reconstruir el razonamiento. |

**Coordinación de roles profesionales:** El docente mantiene la demanda matemática; educación diferencial ajusta acceso, manipulación, lectura o respuesta sin entregar la estrategia ni reducir el OA.

## Evaluación integradora y realidad escolar
Evalúa contenido, respuesta al verbo, evidencia o razonamiento y comunicación/revisión. Registra evidencia individual. La propuesta funciona con pizarra, cuaderno y materiales disponibles; la conectividad no es requisito. En cursos numerosos usa respuestas simultáneas, estaciones y grupos temporales. Considera diversidad lingüística, cultural, sensorial y motriz.
