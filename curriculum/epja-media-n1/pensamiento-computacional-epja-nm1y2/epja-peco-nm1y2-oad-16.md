### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Hoy aprenderé las bases de Python que se leen y se siguen a mano: tipos de datos, variables, operadores y funciones.

**Lo que ya debo saber.** Ya uso listas, tablas y números en mi vida diaria, como una boleta, un horario o un registro de gastos. Sé que un algoritmo es una secuencia de pasos claros para resolver un problema.

**Explicación.**

En Python, cada valor tiene un tipo. Los básicos son int (números enteros, como 1200), float (números con decimales, como 2.5), str (texto entre comillas, como "pan") y bool (verdadero o falso: True o False). Una variable es un nombre donde se guarda un valor, por ejemplo precio = 1200.

Los operadores aritméticos son + (suma), - (resta), * (multiplicación), / (división con decimales), // (división entera: 17 // 5 es 3) y % (resto: 17 % 5 es 2). Los de comparación son ==, !=, <, >, <= y >=. Con texto, + junta los textos: "3" + "4" da "34". Y multiplicar un texto por un número lo repite.

Una función es un grupo de instrucciones con nombre que se puede reutilizar con distintos valores. Se define con def, entre paréntesis van los parámetros y return entrega el resultado: total(1200, 3) da 3600. En este cuaderno el código se lee y se sigue a mano, sin computador.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| tipo de dato | clase de valor: int, float, str o bool |
| variable | nombre donde se guarda un valor |
| función | grupo de instrucciones con nombre que se reutiliza con distintos valores |
| return | palabra que entrega el resultado de una función |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Reconocer tipos*

Problema: ¿Qué tipo tienen los valores "taller", 42, 3.5 y False?

1. "taller" está entre comillas: es texto.
2. 42 es entero y 3.5 tiene decimales.
3. False es un valor verdadero o falso.

Respuesta: str, int, float y bool

*Ejemplo 2. Llamar una función*

Problema: Con la función total de la ficha, ¿qué devuelve total(800, 2)?

1. La función multiplica precio por cantidad.
2. 800 × 2 = 1600.

Respuesta: 1600

**Errores frecuentes y cómo reconocerlos**

- **Error:** Escribir un número entre comillas y esperar que se calcule. **Por qué ocurre:** Con comillas es texto: "3" + "4" da "34" y no 7. **Cómo corregirlo:** Escribe los números sin comillas para calcular.
- **Error:** Usar == para guardar un valor en una variable. **Por qué ocurre:** == compara dos valores y no guarda nada. **Cómo corregirlo:** Para guardar usa un solo =.

**Solucionario razonado**

- **R1.** B) str (texto). Lo que va entre comillas es texto.
- **R2.** C) int (entero). 1200 es un número entero sin decimales ni comillas.
- **R3.** A) bool. Un bool solo puede ser verdadero o falso.
- **C1.** 3.600. Se multiplica el valor guardado en precio por 3. Cálculo: 1200 × 3 = 3.600.
- **C2.** B) float (decimal). Un número con parte decimal es de tipo float.
- **C3.** A) 34. Con texto, el signo + junta los textos.
- **A1.** B) 5000. La función multiplica el precio por la cantidad.
- **A2.** 2.000. La función multiplica 500 por 4. Cálculo: 500 × 4 = 2.000.
- **A3.** A) 3 y 2. 17 // 5 es la división entera y 17 % 5 es el resto.
- **Z1.** B) Repite el texto tres veces: «120012001200», no calcula 3600. Multiplicar un texto por un número lo repite.
- **Z2.** B) para reutilizar un grupo de pasos con distintos valores. Una función evita repetir el mismo código muchas veces.
- **D1.** A) 12. doble(3) es 6 y doble(6) es 12.
- **D2.** A) 1500. La segunda línea guarda el valor anterior más 300.
- **S1.** C) 1100. 1000 // 10 es 100 y se suma al monto: 1100.
- **E1.** La clase de valor: int, float, str o bool. El tipo decide qué operaciones se pueden hacer con el valor.
- **E2.** El resultado de la función. Es el valor que la función devuelve a quien la llamó.
- **E3.** / da decimales y // da la parte entera. La división entera descarta lo que sobra después de la coma.

**Adaptación a 45 minutos:** Conserva la situación cotidiana, el modelado breve, la práctica con apoyo y el cierre oral; reduce la cantidad de casos para quien llega tarde o debe retirarse antes, sin quitar el desafío.
