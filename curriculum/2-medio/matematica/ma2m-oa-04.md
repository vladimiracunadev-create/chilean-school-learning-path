### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a resolver ecuaciones de la forma ax² = b, con ayuda de cuadrados dibujados, y a decidir cuántas soluciones reales tienen. Sirve para hallar el lado de un cuadrado a partir de su área.

**Lo que ya debo saber.** Sé calcular raíces cuadradas de cuadrados perfectos. Sé despejar en ecuaciones lineales y trabajar con fracciones y decimales.

**Explicación.**

Una ecuación cuadrática de la forma ax² = b se resuelve despejando x²: x² = b/a. Si b/a es positivo, hay dos soluciones opuestas, x = √(b/a) y x = −√(b/a), porque los dos números elevados al cuadrado dan b/a. Por ejemplo, 4x² = 25 da x² = 25/4 y x = 5/2 o x = −5/2.

Si b/a es 0, la única solución es x = 0. Si b/a es negativo no hay solución real, porque un número real al cuadrado nunca es negativo. Por ejemplo, 2x² = −8 no tiene solución real. Cuando a y b son fracciones o decimales, se despeja igual: 0,5x² = 8 da x² = 16.

Se puede ver con un dibujo: un cuadrado de lado x tiene área x², y a cuadrados iguales juntan área ax². Si el área total es b, cada cuadrado tiene b/a, y su lado es la raíz de ese valor. En un problema de medidas solo sirve la solución positiva, pero la ecuación tiene las dos.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| ecuación cuadrática | ecuación en que la incógnita aparece elevada al cuadrado |
| solución | valor de x que cumple la ecuación |
| solución real | solución que es un número real |
| despejar | dejar la incógnita sola en un lado |
| opuestos | números con el mismo tamaño y signo contrario |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Dos soluciones*

Problema: Resuelve 3x² = 75.

1. Divido por 3: x² = 25.
2. Los números cuyo cuadrado es 25 son 5 y −5.
3. Compruebo: 3 · 5² = 75 y 3 · (−5)² = 75.

Respuesta: x = 5 o x = −5

*Ejemplo 2. Sin solución real*

Problema: Resuelve 2x² = −8.

1. Divido por 2: x² = −4.
2. Ningún número real elevado al cuadrado es negativo.

Respuesta: No tiene solución real

**Errores frecuentes y cómo reconocerlos**

- **Error:** Resolver x² = 36 y escribir solo x = 6. **Por qué ocurre:** Se olvida que (−6)² también es 36. **Cómo corregirlo:** Escribe las dos soluciones: x = 6 y x = −6 (se escribe ±6).
- **Error:** Resolver 4x² = 25 como x = √25 = 5, sin dividir por 4. **Por qué ocurre:** Se saca la raíz antes de despejar x². **Cómo corregirlo:** Primero divide: x² = 25/4, y luego x = ±5/2.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a resolver ecuaciones de la forma (ax + b)² = c sacando la raíz a ambos lados. Sirve para hallar medidas cuando un cuadrado tiene lado con una parte desconocida.

**Lo que ya debo saber.** Sé resolver x² = k. Sé resolver ecuaciones lineales con fracciones.

**Explicación.**

En (ax + b)² = c, el cuadrado está sobre todo el paréntesis. Si c es positivo, el paréntesis puede ser √c o −√c, y se resuelven dos ecuaciones lineales: ax + b = √c y ax + b = −√c. Por ejemplo, (x − 3)² = 16 da x − 3 = 4 o x − 3 = −4, es decir x = 7 o x = −1.

Si c = 0 hay una sola solución, porque ax + b = 0. Si c es negativo no hay solución real. Con fracciones se trabaja igual: (x + 1/2)² = 9/4 da x + 1/2 = ±3/2, entonces x = 1 o x = −2. Siempre comprueba reemplazando en la ecuación original.

Un dibujo ayuda: un cuadrado de lado (x + 2) tiene área (x + 2)². Si el área es 49, el lado mide 7 y por eso x + 2 = 7. En una medida de longitud solo sirve el lado positivo, pero la ecuación abstracta tiene dos soluciones. No se debe separar (x + 2)² como x² + 4.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| binomio | expresión con dos términos, como x + 2 |
| cuadrado de un binomio | (x + 2)², el binomio multiplicado por sí mismo |
| raíz cuadrada positiva y negativa | los dos números cuyo cuadrado es c: √c y −√c |
| comprobar | reemplazar una solución en la ecuación original |
| solución única | caso en que solo hay un valor posible |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Dos soluciones*

Problema: Resuelve (x + 2)² = 49.

1. Saco la raíz: x + 2 = 7 o x + 2 = −7.
2. Despejo: x = 5 o x = −9.
3. Compruebo: (5 + 2)² = 49 y (−9 + 2)² = (−7)² = 49.

Respuesta: x = 5 o x = −9

*Ejemplo 2. Con coeficiente*

Problema: Resuelve (3x − 1)² = 4.

1. 3x − 1 = 2 o 3x − 1 = −2.
2. Primera: 3x = 3, entonces x = 1.
3. Segunda: 3x = −1, entonces x = −1/3.

Respuesta: x = 1 o x = −1/3

**Errores frecuentes y cómo reconocerlos**

- **Error:** Resolver (x − 3)² = 16 y escribir solo x − 3 = 4. **Por qué ocurre:** Se olvida la raíz negativa. **Cómo corregirlo:** Escribe también x − 3 = −4, de donde x = −1.

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a resolver ecuaciones de la forma ax² + bx = 0 con factor común. Sirve para hallar cuándo una cantidad vale cero, como una altura o una ganancia.

**Lo que ya debo saber.** Sé sacar factor común. Sé que un producto es 0 solo si algún factor es 0.

**Explicación.**

En ax² + bx = 0, los dos términos tienen x. Se saca factor común: x(ax + b) = 0. Un producto es 0 solo si algún factor es 0, así que x = 0 o ax + b = 0. De la segunda se obtiene x = −b/a. Por ejemplo, 3x² − 12x = 0 se escribe 3x(x − 4) = 0 y las soluciones son 0 y 4.

Esta ecuación tiene siempre la solución x = 0, y una segunda solución distinta si b no es 0. Con fracciones o decimales se factoriza igual: 0,5x² − 3x = 0 da x(0,5x − 3) = 0, entonces x = 0 o x = 6. Si hay un denominador, multiplica toda la ecuación para eliminarlo.

Cuidado: no se debe dividir por x. En x² = 5x, dividir por x deja x = 5 y se pierde la solución x = 0. Lo correcto es pasar todo a un lado: x² − 5x = 0 y factorizar x(x − 5) = 0. Siempre comprueba ambas soluciones en la ecuación original.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| factor común | factor que está en todos los términos |
| producto nulo | si a · b = 0, entonces a = 0 o b = 0 |
| factorizar | escribir una suma como producto |
| solución | valor de x que hace verdadera la ecuación |
| término | parte de una suma, como 3x² o −12x |

### Cuaderno del estudiante

**Lo que aprenderé y para qué sirve.** Aprenderé a resolver ecuaciones de la forma ax² + bx = c llevándolas a cero y comparando dos estrategias: factorizar y completar el cuadrado. Sirve para hallar medidas cuando el área está dada.

**Lo que ya debo saber.** Sé factorizar trinomios con números enteros. Sé resolver (x + k)² = c.

**Explicación.**

Para resolver ax² + bx = c, primero pasa todo a un lado y deja la forma ax² + bx − c = 0. Si el trinomio se puede factorizar, se factoriza y se iguala cada factor a 0. Por ejemplo x² − x = 6 se escribe x² − x − 6 = 0, es decir (x − 3)(x + 2) = 0, y las soluciones son 3 y −2.

Otra estrategia es completar el cuadrado. Para x² + 6x = 16, suma 9 (el cuadrado de la mitad de 6) a ambos lados: x² + 6x + 9 = 25, o sea (x + 3)² = 25. Entonces x + 3 = ±5 y x = 2 o x = −8. Esta estrategia funciona aunque no veas los factores a simple vista.

Cuando a no es 1, se puede dividir por a o factorizar con cuidado: 2x² − 3x − 2 = (2x + 1)(x − 2). Siempre comprueba reemplazando. Si la ecuación es x(x + 1) = 6, no vale decir x = 6 o x + 1 = 6: esa regla solo funciona cuando el producto es 0.

**Palabras importantes**

| Palabra | Qué significa |
|---|---|
| forma general | ax² + bx + c = 0 |
| completar el cuadrado | sumar lo necesario para formar (x + k)² |
| trinomio | expresión con tres términos |
| factorizar | escribir como producto |
| comprobación | reemplazar para verificar |

**Ejemplos resueltos paso a paso**

*Ejemplo 1. Completar el cuadrado*

Problema: Resuelve x² + 6x = 16.

1. La mitad de 6 es 3 y 3² = 9; sumo 9 a ambos lados: x² + 6x + 9 = 25.
2. (x + 3)² = 25, entonces x + 3 = 5 o x + 3 = −5.
3. x = 2 o x = −8.

Respuesta: x = 2 o x = −8

*Ejemplo 2. Factorizar*

Problema: Resuelve 2x² − 3x = 2.

1. Paso a cero: 2x² − 3x − 2 = 0.
2. Factorizo: (2x + 1)(x − 2) = 0.
3. 2x + 1 = 0 da x = −1/2 y x − 2 = 0 da x = 2.

Respuesta: x = 2 o x = −1/2

**Errores frecuentes y cómo reconocerlos**

- **Error:** Resolver x(x + 8) = 20 como x = 20 o x + 8 = 20. **Por qué ocurre:** Se usa la regla del producto nulo con un producto distinto de 0. **Cómo corregirlo:** Desarrolla: x² + 8x − 20 = 0, que es (x + 10)(x − 2) = 0, con x = −10 o x = 2.
- **Error:** Resolver x² − 4x = 5 factorizando x(x − 4) = 5 y escribiendo x = 5. **Por qué ocurre:** Se pasa un solo término y se factoriza sin igualar a 0. **Cómo corregirlo:** Pasa todo a un lado: x² − 4x − 5 = 0, (x − 5)(x + 1) = 0, entonces x = 5 o x = −1.

**Ejercicios**

*Recuperación*

- **R1.** Escribe x² + 4x = 12 en la forma x² + bx + c = 0.
- **R2.** ¿Es x = 2 solución de x² + 4x = 12? A) No B) Sí
- **R3.** Resuelve (x + 6)(x − 2) = 0.

*Comprensión*

- **C1.** Resuelve x² − x = 6.
- **C2.** ¿Qué número completa el cuadrado: x² + 10x + __ = (x + 5)²?
- **C3.** Resuelve 2x² + 5x = 3.

*Aplicación*

- **A1.** Un rectángulo tiene ancho x m y largo (x + 3) m, con área 40 m². ¿Cuánto mide el ancho?
- **A2.** El cuadrado de un número más el doble del número da 15. ¿Qué números cumplen x² + 2x = 15?
- **A3.** Resuelve 3x² + 2x = 1.

*Razonamiento y análisis*

- **Z1.** Ana resuelve x(x + 3) = 10 y dice x = 10 o x + 3 = 10. ¿Está bien? A) Sí B) No
- **Z2.** ¿Cuántas soluciones tiene x² − 6x = −9?

*Desafío*

- **D1.** x² + bx = 24 tiene la solución x = 4. ¿Cuánto vale b y cuál es la otra solución?
- **D2.** Resuelve (1/2)x² + x = 4.

*Situaciones auténticas*

- **S1.** Un rectángulo de ejemplo tiene ancho x m y largo (x + 7) m, y su área es 60 m². ¿Cuánto mide el ancho?

*Autoevaluación*

- **E1.** Resuelve x² + 3x = 28.
- **E2.** Resuelve x² − 4x = −4.
- **E3.** Verdadero o falso: si x(x + 1) = 6, entonces x = 6 o x + 1 = 6.

**Actividad abierta.** Resuelve estas dos ecuaciones con dos estrategias distintas: x² + 8x = 9 (completando el cuadrado) y x² − 2x = 15 (factorizando). Comprueba las soluciones y escribe cuál estrategia te pareció más corta en cada caso.

**Solucionario razonado**

- **R1.** x² + 4x − 12 = 0. Se resta 12 en ambos lados.
- **R2.** B. 4 + 8 = 12.
- **R3.** x = −6 o x = 2. Cada factor puede ser 0.
- **C1.** x = 3 o x = −2. x² − x − 6 = (x − 3)(x + 2).
- **C2.** 25. Es el cuadrado de la mitad de 10: 5² = 25.
- **C3.** x = 1/2 o x = −3. 2x² + 5x − 3 = (2x − 1)(x + 3).
- **A1.** 5 m. x² + 3x − 40 = (x + 8)(x − 5) y x debe ser positivo.
- **A2.** 3 y −5. x² + 2x − 15 = (x + 5)(x − 3).
- **A3.** x = 1/3 o x = −1. 3x² + 2x − 1 = (3x − 1)(x + 1).
- **Z1.** B. Esa regla solo vale si el producto es 0; x = 2 da 2 · 5 = 10, y x = 10 da 130.
- **Z2.** Una (x = 3). x² − 6x + 9 = (x − 3)² = 0.
- **D1.** b = 2; otra solución x = −6. 16 + 4b = 24 da b = 2, y x² + 2x − 24 = (x + 6)(x − 4).
- **D2.** x = 2 o x = −4. Multiplicando por 2: x² + 2x − 8 = (x + 4)(x − 2).
- **S1.** 5 m. x² + 7x − 60 = (x + 12)(x − 5) y solo x = 5 es positivo.
- **E1.** x = 4 o x = −7. x² + 3x − 28 = (x + 7)(x − 4).
- **E2.** x = 2. x² − 4x + 4 = (x − 2)² = 0.
- **E3.** Falso. Esa regla solo vale con 0; x = 2 da 2 · 3 = 6 y x = 6 da 42.

**Actividad abierta · ejemplo de respuesta.** x² + 8x = 9: x² + 8x + 16 = 25, (x + 4)² = 25, x = 1 o x = −9. x² − 2x − 15 = (x − 5)(x + 3) = 0, x = 5 o x = −3. Comprobación: 1 + 8 = 9; 25 − 10 = 15.

**Criterios para evaluarla:** pasa a cero o completa el cuadrado correctamente; da todas las soluciones; comprueba y compara estrategias.

**Evidencias aceptables:** dos resoluciones con pasos; comprobación.

**Errores que conviene detectar:** usar el producto nulo con un producto distinto de 0; olvidar sumar el mismo número en ambos lados.

**Retroalimentación constructiva:** Si una solución falla en la comprobación, pide revisar el paso en que se pasó un término al otro lado.

**Refuerzo.** Resuelve x² + 2x = 8, x² − 5x = −6 y 2x² + x = 6.

**Profundización.** Completa el cuadrado en x² + 3x = 4 (usa fracciones) y compara con la factorización.


**Apoyo en el mismo OA:** Reduce temporalmente el rango o la cantidad, conserva la relación matemática y permite material concreto, tabla, recta o dibujo antes del símbolo; después retorna al desafío original.

**Profundización:** Cambia una condición de baldosas algebraicas, áreas, productos nulos y ecuaciones de las formas oficiales con soluciones racionales verificables, predice el efecto y crea un contraejemplo que obligue a revisar la estrategia inicial.

**Evidencia:** Solución individual sobre comparar estrategias: ecuaciones cuadráticas en formas resolubles con representación pertinente, razonamiento visible, unidad y comprobación.

**Criterios de éxito:** responde al foco matemático de la clase; usa una representación o estrategia pertinente; fundamenta y comprueba la solución.

**Decisión posterior:** Avanza si representación, cálculo y explicación coinciden; si no, identifica si la barrera está en el concepto, la representación, el procedimiento o la comprobación y reenseña con un caso diferente.

**Adaptación a 45 minutos:** Conserva el desafío, un modelado breve, práctica conjunta, evidencia individual y ticket; reduce repeticiones, no la demanda matemática.

**Tarea breve y flexible:** Crea o busca un ejemplo cotidiano seguro del foco y explícalo con dibujo, nota u oralidad. No requiere internet, impresión, compras ni datos familiares.

**Actividades complementarias (opcionales):**
- Recuperación: resolver un caso con menor carga y volver al original.
- Análisis de error: corregir un caso ficticio que muestra esta confusión: aplicar una fórmula única sin reconocer estructura, restricciones ni comprobar cada solución.
- Transferencia: cambiar una condición o representación y revisar la respuesta.

**Control de dificultades en el aula**

| Dificultad observable | Acción inmediata | Cómo comprobar si funcionó |
|---|---|---|
| Responde antes de examinar datos o representación | Pide señalar la evidencia que usará y anticipar cómo la comprobará. | La nueva respuesta muestra datos y comprobación pertinentes. |
| Aplicar una fórmula única sin reconocer estructura, restricciones ni comprobar cada solución | Vuelve a una representación concreta o pictórica, contrasta dos casos y retoma el desafío simbólico. | Resuelve un caso nuevo sin repetir la confusión y explica la diferencia. |
| Obtiene un resultado, pero no puede justificarlo | Solicita comparar con otra estrategia y nombrar el criterio decisivo. | La explicación permite reconstruir el razonamiento. |

**Coordinación de roles profesionales:** El docente mantiene la demanda matemática; educación diferencial ajusta acceso, manipulación, lectura o respuesta sin entregar la estrategia ni reducir el OA.

**Integración de habilidad y actitud:**
- **Habilidad · `de Habilidad MA2M OAH b`:** Se observa al entender, planificar, resolver y comprobar mientras se alcanza la meta «aprenderé a comparar estrategias: Ecuaciones cuadráticas en formas resolubles; mostraré mi estrategia y comprobaré si mi respuesta tiene sentido».
- **Actitud · `de Actitud MA2M OAA E`:** Se promueve esfuerzo y perseverancia ante un desafío; se valora explicar, comprobar y revisar, no la rapidez.

## Evaluación integradora y realidad escolar
Evalúa contenido, respuesta al verbo, evidencia o razonamiento y comunicación/revisión. Registra evidencia individual. La propuesta funciona con pizarra, cuaderno y materiales disponibles; la conectividad no es requisito. En cursos numerosos usa respuestas simultáneas, estaciones y grupos temporales. Considera diversidad lingüística, cultural, sensorial y motriz.
