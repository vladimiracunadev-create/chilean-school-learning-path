## Límites

- Completar dos asignaturas no convierte el nivel completo en desarrollo terminado.
- Las clases cumplen el contrato automatizado, pero siguen pendientes de revisión humana disciplinar y pedagógica.
- La oferta no constituye un horario obligatorio ni sustituye la planificación institucional.
