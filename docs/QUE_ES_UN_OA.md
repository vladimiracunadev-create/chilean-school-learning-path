# ¿Qué es un OA?

**OA significa Objetivo de Aprendizaje.** Es una declaración oficial de lo que una o un estudiante debe llegar a comprender, hacer o comunicar durante su trayectoria escolar.

Un OA no es una clase, una actividad, una tarea ni una página del repositorio. Un mismo OA suele requerir varias clases: primero se recuperan ideas, luego se modela, se practica, se aplica y se recoge evidencia.

## Cómo leer un código

`MA01 OA 01` se puede leer así:

| Parte | Significado |
|---|---|
| `MA` | Matemática |
| `01` | 1° básico |
| `OA` | Objetivo de Aprendizaje |
| `01` | número del objetivo dentro de la asignatura y nivel |

También existen objetivos de habilidades o actitudes con códigos distintos. La ficha siempre muestra el texto oficial completo; el código sirve para identificarlo y encontrar su fuente.

## OA, clase, actividad y evidencia

| Elemento | Pregunta que responde | Ejemplo |
|---|---|---|
| OA | ¿Qué aprendizaje se espera? | contar hacia adelante y atrás usando distintos intervalos |
| Clase | ¿Qué avance se trabajará hoy? | comparar dos formas de contar y explicar una regularidad |
| Actividad | ¿Qué harán para aprender? | ordenar tarjetas, contar colecciones y corregir una secuencia |
| Evidencia | ¿Qué permitirá saber si aprendieron? | una secuencia propia, representada y explicada |
| Tarea | ¿Cómo consolidarán brevemente? | encontrar un ejemplo cotidiano y comprobarlo |

## Cómo lo usa este proyecto

1. Conserva el texto y enlace de la fuente oficial.
2. Estima una secuencia de 4 a 7 clases según la amplitud del OA.
3. Da a cada clase un código estable `CL-xxxxx`.
4. Publica cada secuencia en Markdown y HTML.
5. Distingue si está inventariada, desarrollada, revisada y publicada.

Completar una actividad no demuestra por sí solo el OA. La ficha pide una evidencia individual y una decisión posterior: avanzar, apoyar o reenseñar.

## Ejemplo completo

En `MA01 OA 01`, la fuente espera que el estudiante cuente en distintos intervalos, direcciones y puntos de partida. Una sola hoja de ejercicios no cubre todo eso. Por eso la secuencia propone cuatro clases: diagnóstico, modelado, aplicación autónoma y demostración con revisión.
