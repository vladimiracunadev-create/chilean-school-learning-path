# Glosario educativo

Términos y siglas usados en Trayectoria Escolar Chile. Las definiciones explican cómo se emplean en este repositorio; cuando una expresión tiene alcance normativo, prevalece su fuente oficial.

| Término | Significado en el proyecto |
|---|---|
| **OA** | Objetivo de Aprendizaje: resultado que una o un estudiante debe llegar a comprender, hacer o comunicar. No es una clase ni una actividad. |
| **OAH** | Objetivo asociado a habilidades. El código puede aparecer como “de Habilidad”; su texto y fuente se conservan en la ficha. |
| **OAA** | Objetivo asociado a actitudes. No debe transformarse automáticamente en una conducta para calificar. |
| **OF** | Objetivo Fundamental presente en algunas estructuras curriculares registradas por la fuente. |
| **Eje** | Organización temática o disciplinar que agrupa objetivos relacionados. |
| **Nivel** | Curso escolar al que la fuente curricular asocia el objetivo. |
| **Cobertura** | Condición con que una asignatura u objetivo forma parte de la oferta: formación común, propuesta, según contexto o electivo. |
| **Dosificación** | Distribución inicial de un OA en 4 a 7 clases. Orienta; no obliga a avanzar por calendario. |
| **Secuencia** | Conjunto ordenado de clases que desarrolla un OA desde diagnóstico hasta evidencia y retroalimentación. |
| **Clase** | Propuesta pedagógica identificada con un código `CL-xxxxx`, un propósito, experiencias y evidencia. |
| **Actividad** | Acción concreta que realizan estudiantes para aprender. Una actividad no demuestra por sí sola el OA. |
| **Tarea flexible** | Consolidación breve, sin dependencia de internet o compras, que admite vías pertinentes de respuesta. |
| **Actividad complementaria** | Opción de recuperación, práctica o profundización elegida según evidencia; no es una lista obligatoria. |
| **Evidencia** | Producción o desempeño observable que permite interpretar el aprendizaje de un estudiante. |
| **Criterio de éxito** | Rasgo observable usado para analizar la evidencia sin reducirla a participación, rapidez o presentación. |
| **Ticket de salida** | Evidencia breve al cierre que ayuda a decidir el paso siguiente; no es necesariamente una nota. |
| **Modelado** | Demostración en la que el docente hace visibles contenido, decisiones, razones y comprobación. |
| **Práctica guiada** | Ensayo del OA con apoyo y retroalimentación inmediata antes del desempeño autónomo. |
| **Apoyo o andamiaje** | Cambio temporal de acceso, representación, tiempo o respuesta que conserva el OA y se retira gradualmente. |
| **Profundización** | Comparación, justificación, creación o transferencia para quien ya evidencia dominio; no significa más repetición. |
| **Transferencia** | Uso del aprendizaje en una situación diferente del ejemplo enseñado. |
| **Reenseñanza** | Nueva explicación, representación o experiencia ante una barrera persistente; no es repetir más fuerte lo mismo. |
| **Evaluación formativa** | Recogida e interpretación de evidencia para decidir cómo continuar la enseñanza. |
| **UTP** | Unidad Técnico-Pedagógica o función equivalente de coordinación curricular en el establecimiento. |
| **CRA** | Centro de Recursos para el Aprendizaje o biblioteca escolar. |
| **PIE** | Programa de Integración Escolar. Su existencia y profesionales dependen del establecimiento y la normativa aplicable. |
| **Inventariada** | La clase tiene OA, nivel, asignatura, eje y fuente identificados. |
| **Secuenciada** | La clase tiene posición y dosificación propuestas. |
| **Desarrollada** | Cumple el contrato pedagógico definido por el proyecto. No implica revisión humana. |
| **Revisada** | Una persona competente dejó evidencia de una revisión según el protocolo. |
| **Publicada** | Existe y es navegable en Markdown y HTML. No equivale a desarrollada ni revisada. |

## Códigos rápidos

- `MA01 OA 01`: Matemática · 1° básico · OA número 1.
- `CL-00746`: identificador estable de una clase del catálogo.
- `ma01-oa-01.md`: archivo Markdown del OA.
- `ma01-oa-01.html`: página HTML equivalente.
