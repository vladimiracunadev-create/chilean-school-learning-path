# Control de dificultades en el aula con acciones

Una dificultad se describe por lo que se observa, no por una etiqueta sobre el estudiante. El ciclo recomendado es: **observar → actuar → comprobar → decidir**. Si la primera acción no cambia la evidencia, se cambia la vía; no se repite lo mismo con mayor presión.

## Matriz operativa

| Dificultad observable | Acción inmediata | Cómo comprobar | Decisión siguiente |
|---|---|---|---|
| No inicia la consigna | reducirla a un paso, modelar con un ejemplo diferente y pedir que señale qué hará primero | inicia sin copiar el ejemplo | entregar el segundo paso o cambiar representación |
| No comprende vocabulario | mostrar objeto, gesto, imagen o ejemplo/no ejemplo y usar la palabra en una frase | explica o usa la palabra en el contexto | retirar el apoyo gradualmente |
| Participan siempre los mismos | usar respuesta simultánea, pensar–pareja–compartir o tarjetas de todos | existe evidencia de cada estudiante | formar grupos temporales según respuestas |
| Copia, pero no explica | retirar el modelo, cambiar un dato y pedir representación o decisión propia | sostiene una respuesta sin el ejemplo visible | volver a modelar el criterio, no el producto |
| Se frustra o abandona | ofrecer pausa breve, dos vías posibles y un intento acotado sin exposición pública | retoma y completa un intento | mantener apoyo o solicitar coordinación profesional |
| Termina rápido | pedir comparación, caso límite, creación o transferencia | justifica y revisa una decisión nueva | profundizar; no agregar repetición mecánica |
| El curso pierde foco | detener, mostrar la regla en 30 segundos, asignar turnos/roles y reiniciar con tiempo visible | completa un ciclo respetando la regla | ajustar duración, agrupamiento o transición |
| Aparece un conflicto | asegurar calma, separar el problema de las personas, restituir seguridad y retomar solo si corresponde | participantes pueden continuar de forma segura | aplicar protocolo y seguimiento fuera de la exposición grupal |
| Faltó a clases previas | entregar una experiencia puente con idea, ejemplo y evidencia mínima | demuestra el prerrequisito esencial | incorporar a la secuencia o recuperar en grupo breve |
| La lectura/escritura oculta lo que sabe | permitir respuesta oral, manipulativa, gráfica o con apoyo tecnológico si el OA no evalúa esa modalidad | se observa el aprendizaje central | documentar vía eficaz sin bajar el OA |
| Material o internet no está disponible | usar pizarra, cuaderno, objetos del entorno o tarjetas reutilizables | la experiencia conserva propósito y evidencia | registrar alternativa para la próxima planificación |

## Semáforo de intervención

- **Verde:** una pista permite continuar; se retira y se registra la evidencia.
- **Amarillo:** la barrera persiste; se cambia representación, agrupamiento o tiempo y se recoge otra evidencia.
- **Rojo:** existe riesgo, exposición emocional, crisis o posible vulneración; se protege, se detiene la demanda y se activa el protocolo institucional correspondiente.

## Registro breve

Anota solo lo necesario: fecha, OA, dificultad observable, acción aplicada, evidencia posterior y decisión. Evita diagnósticos, juicios de personalidad y datos sensibles innecesarios.

Cada clase desarrollada de 1° básico incorpora cinco dificultades frecuentes con acción inmediata y comprobación contextualizada.
