## Límites

- Seis denominaciones tienen desarrollo interno completo; el nivel mantiene propuestas pendientes en las otras cinco.
- Las clases cumplen el contrato automatizado, pero siguen pendientes de revisión humana disciplinar y pedagógica.
- Completar una asignatura no significa imponer toda la oferta como horario ni sustituir la planificación institucional.
